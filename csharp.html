Chapter 2: LINQ (Data Mastery)

LINQ is C#'s most powerful feature. It allows you to query any data source (Lists, Databases, XML) using a SQL-like syntax.

/* Pro LINQ Query */
var topEmployees = employees
    .Where(e => e.Sales > 10000)
    .OrderByDescending(e => e.Rating)
    .Select(e => new { e.Name, e.Department })
    .ToList();

Chapter 3: Async & Task Parallel Library

Responsive apps require asynchronous programming. Master Task, async, and await to handle long-running operations without blocking the UI.

public async Task<User> GetUserAsync(int id)
{
    // Non-blocking I/O operation
    var result = await _apiClient.GetAsync($"/users/{id}");
    return await result.Content.ReadAsAsync<User>();
}
