CSS (Cascading Style Sheets) is the styling language used to describe the presentation, design, colors, and layout of a document written in HTML. Without CSS, the web would be plain black text on white backgrounds with blue links.

There are three ways to apply CSS to an HTML document:

  • External CSS: Inside a separate .css file linked via <link rel="stylesheet" href="style.css"> (The industry standard for clean architecture).
  • Internal CSS: Inside a <style> tag located within the HTML <head>.
  • Inline CSS: Directly inside an HTML tag using the style="..." attribute (Recommended only for dynamic email templates or JS overrides).

Understanding The Cascade: The word "Cascading" means rules flow downward. When multiple styles target the same HTML element, CSS resolves conflicts using three criteria: Importance (e.g. !important), Specificity (how specific the selector is), and Source Order (the last rule declared wins).

CSS Rule Syntax

h1 {
  /* Property: What to change | Value: How to change it */
  color: #2dd4bf;
  font-size: 2.5rem;
  text-align: center;
}
Key Takeaway: Always prefer external stylesheets. They can be cached by browsers, drastically improving load speed and user experience.

Selectors tell CSS exactly which HTML elements to apply styles to. Mastering selectors and specificity is the secret to avoiding messy CSS overrides and styling bugs.

Core Selectors:

  • Element: p { ... } (Targets all paragraphs).
  • Class: .btn { ... } (Targets any element with class="btn". Reusable).
  • ID: #navbar { ... } (Targets the unique element with id="navbar").
  • Attribute: input[type="email"] { ... } (Targets specific input types).

Combinators & Pseudo-classes:

  • Descendant (space): nav a targets all <a> inside nav.
  • Direct Child (>): ul > li targets direct children only.
  • Pseudo-classes: :hover (when hovered), :focus (when focused), :nth-child(even) (every alternate element).
  • Pseudo-elements: ::before and ::after for inserting decorative content without extra HTML.

Every single visible element on a web page is rendered as a rectangular box. The CSS Box Model defines the dimensions and spacing around that box through four layers:

  1. Content: The text, image, or media itself.
  2. Padding: The transparent space between the content and the border.
  3. Border: The outline wrapping the padding and content.
  4. Margin: The transparent space outside the border separating the element from neighbors.

The Most Important CSS Rule: box-sizing: border-box

By default, CSS uses box-sizing: content-box, meaning if you set a width of 200px and add 20px padding, the total rendered width becomes 240px. With border-box, the padding and border are included inside the 200px width. Modern developers apply this globally:

Global Box-Sizing Reset
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

/* Card with explicit padding and border */
.card {
  width: 320px;
  padding: 24px;
  border: 1px solid var(--cl-line);
  margin-bottom: 24px;
  background: var(--cl-surface);
}

Display Properties: block (starts on new line, takes full width), inline (flows with text, ignores top/bottom margins), inline-block (flows inline but respects width/height), and none (completely removes from document flow).

More than 60% of all web traffic comes from mobile devices. Responsive Web Design (RWD) ensures your website looks beautiful and functions smoothly across phones, tablets, laptops, and ultra-wide desktops.

The Mobile-First Strategy: Write your default CSS for mobile screens without media queries. Then, use @media (min-width: ...) to progressively add complexity as screen width expands. This improves mobile performance and simplifies CSS logic.

  padding: 16px;
  flex-direction: column;
}

/* 2. Tablet (min-width: 768px) */
@media (min-width: 768px) {
  .container {
    padding: 32px;
    flex-direction: row;
  }
}

/* 3. Desktop (min-width: 1024px) */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}

/* Fluid Typography with clamp() */
h1 {
  /* clamp(min, preferred, max) */
  font-size: clamp(1.75rem, 4vw + 1rem, 3.5rem);
}
