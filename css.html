Chapter 1: The Modern Grid Strategy

In 2026, choosing between Flexbox and Grid is about dimensionality. Use Flexbox for 1D (rows OR columns) and Grid for 2D (rows AND columns).

/* Pro Holy Grail Layout with CSS Grid */
.parent {
  display: grid;
  grid-template-areas: 
    "header header"
    "nav main"
    "footer footer";
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

header { grid-area: header; }
nav { grid-area: nav; }
main { grid-area: main; }
footer { grid-area: footer; }

Chapter 2: Variables & Design Systems

Stop hardcoding colors. CSS Variables (Custom Properties) allow you to change your entire theme in seconds.

:root {
  --primary: #3b82f6;
  --bg: #ffffff;
}

[data-theme="dark"] {
  --primary: #60a5fa;
  --bg: #0f172a;
}

body {
  background: var(--bg);
  color: var(--primary);
  transition: background 0.3s ease;
}

Chapter 3: Advanced Selectors (:has, :is)

The :has() selector is the "parent selector" developers waited 20 years for. It lets you style an element based on its children.

/* Style the card ONLY if it contains an image */
.card:has(img) {
  padding: 0;
  display: block;
}

/* Grouping selectors cleanly with :is() */
:is(header, main, footer) h2 {
  color: var(--cl-brand);
  font-weight: 800;
}

Chapter 4: Performance & Reflow

Professional CSS is about performance. Animating properties like width or top causes "Reflow" (slow). Use transform and opacity for GPU-accelerated 60fps animations.

Rule of Thumb: Only animate transform and opacity. Avoid anything that changes the size or position of other elements on the page.
