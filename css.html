Lesson 1 — Introduction to CSS3 & How the Cascade Works

Beginner

الدرس 1 — مقدمة في CSS3 وكيفية عمل التعاقب (The Cascade)

مبتدئ

CSS (Cascading Style Sheets) is the styling language used to describe the presentation, design, colors, and layout of a document written in HTML. Without CSS, the web would be plain black text on white backgrounds with blue links.

There are three ways to apply CSS to an HTML document:

  • External CSS: Inside a separate .css file linked via <link rel="stylesheet" href="style.css"> (The industry standard for clean architecture).
  • Internal CSS: Inside a <style> tag located within the HTML <head>.
  • Inline CSS: Directly inside an HTML tag using the style="..." attribute (Recommended only for dynamic email templates or JS overrides).

Understanding The Cascade: The word "Cascading" means rules flow downward. When multiple styles target the same HTML element, CSS resolves conflicts using three criteria: Importance (e.g. !important), Specificity (how specific the selector is), and Source Order (the last rule declared wins).

CSS Rule Syntax
/* Selector: Targets the element */
h1 {
  /* Property: What to change | Value: How to change it */
  color: #2dd4bf;
  font-size: 2.5rem;
  text-align: center;
}
Key Takeaway: Always prefer external stylesheets. They can be cached by browsers, drastically improving load speed and user experience.

CSS (Cascading Style Sheets - أوراق الأنماط المتعاقبة) هي لغة التنسيق والتصميم المسؤولة عن المظهر البصري، الألوان، الخطوط، وتوزيع العناصر لصفحات الويب المكتوبة بـ HTML.

توجد ثلاث طرق رئيسية لربط CSS بملفات HTML:

  • CSS خارجي (External): في ملف مستقل بامتداد .css يُربط عبر <link rel="stylesheet" href="style.css"> (المعيار الاحترافي الموصى به دائماً).
  • CSS داخلي (Internal): داخل وسم <style> في رأس الصفحة <head>.
  • CSS سطحي (Inline): داخل الوسم مباشرة بواسطة السمة style="...".

ما هو مفهوم التعاقب (The Cascade)؟ كلمة "متعاقبة" تعني أن القواعد تتدفق من الأعلى للأسفل. عندما تنطبق عدة قواعد تنسيق على نفس العنصر، تحل لغة CSS التضارب عبر ثلاثة معايير: الأهمية، الخصوصية (Specificity)، وترتيب الظهور (Source Order) حيث تطبق القاعدة الأخيرة.

صيغة كتابة قاعدة CSS
/* المحدد (Selector) */
h1 {
  /* الخاصية (Property) : القيمة (Value) */
  color: #2dd4bf;
  font-size: 2.5rem;
  text-align: center;
}
قاعدة ذهبية: اعتمد دائماً على ملفات CSS الخارجية لأن المتصفح يقوم بتخزينها مؤقتاً (Cache)، مما يجعل تحميل الموقع فائق السرعة.

Lesson 2 — Selectors, Combinators & Specificity Hierarchy

Core Skill

الدرس 2 — المحددات (Selectors) والروابط وتراتبية الخصوصية

مهارة أساسية

Selectors tell CSS exactly which HTML elements to apply styles to. Mastering selectors and specificity is the secret to avoiding messy CSS overrides and styling bugs.

Core Selectors:

  • Element: p { ... } (Targets all paragraphs).
  • Class: .btn { ... } (Targets any element with class="btn". Reusable).
  • ID: #navbar { ... } (Targets the unique element with id="navbar").
  • Attribute: input[type="email"] { ... } (Targets specific input types).

Combinators & Pseudo-classes:

  • Descendant (space): nav a targets all <a> inside nav.
  • Direct Child (>): ul > li targets direct children only.
  • Pseudo-classes: :hover (when hovered), :focus (when focused), :nth-child(even) (every alternate element).
  • Pseudo-elements: ::before and ::after for inserting decorative content without extra HTML.
Modern Selectors in Action
/* Button hover & focus state */
.btn-primary {
  background-color: var(--cl-brand);
  color: #fff;
  padding: 12px 24px;
  border-radius: 8px;
  transition: transform 0.2s ease;
}

.btn-primary:hover {
  transform: translateY(-2px);
  filter: brightness(1.1);
}

/* Zebra striping for table rows */
tbody tr:nth-child(even) {
  background-color: rgba(255, 255, 255, 0.03);
}
Specificity Warning: Avoid overusing !important. Specificity points rank: Inline style (1000) > ID (100) > Class/Attribute/Pseudo-class (10) > Element (1). Keep specificity low with utility classes.

المحددات (Selectors) تحدد بدقة العناصر التي ستطبق عليها أنماط CSS. فهم المحددات وقوة التحديد (Specificity) هو المفتاح لكتابة كود نظيف وخالٍ من التعارضات.

أهم أنواع المحددات:

  • محدد العنصر: p { ... } يحدد كل الفقرات.
  • محدد الفئة (Class): .card { ... } يحدد كل عنصر يحمل class="card"، وهو قابل لإعادة الاستخدام.
  • محدد المعرف (ID): #header { ... } يحدد العنصر الفريد فقط.
  • محدد السمة: input[type="submit"] يستهدف عناصر بإدخال محدد.

العناصر الزائفة وحالات التفاعل (Pseudo-classes & Elements):

  • :hover للتفاعل عند تمرير مؤشر الفأرة.
  • :focus عند النقر أو تفعيل حقل الإدخال.
  • :nth-child(2n) لتلوين الصفوف الفردية والزوجية في الجداول والقوائم.
  • ::before و ::after لإنشاء عناصر زخرفية دون تضخيم كود HTML.
أمثلة عملية للمحددات الحديثة
/* زر تفاعلي احترافي */
.btn-primary {
  background-color: var(--cl-brand);
  color: #fff;
  padding: 12px 24px;
  border-radius: 8px;
  transition: transform 0.2s ease;
}

.btn-primary:hover {
  transform: translateY(-2px);
  filter: brightness(1.1);
}

/* تلوين الصفوف المتناوبة */
tbody tr:nth-child(even) {
  background-color: rgba(255, 255, 255, 0.03);
}
تحذير الخصوصية: تجنب استخدام !important. حساب قوة التحديد يبدأ من السطحي (1000) > الـ ID (100) > الكلاس والسمات (10) > العنصر (1).

Lesson 3 — The Box Model & Display Fundamentals

Essential

الدرس 3 — نموذج الصندوق (The Box Model) وخصائص العرض

جوهري

Every single visible element on a web page is rendered as a rectangular box. The CSS Box Model defines the dimensions and spacing around that box through four layers:

  1. Content: The text, image, or media itself.
  2. Padding: The transparent space between the content and the border.
  3. Border: The outline wrapping the padding and content.
  4. Margin: The transparent space outside the border separating the element from neighbors.

The Most Important CSS Rule: box-sizing: border-box

By default, CSS uses box-sizing: content-box, meaning if you set a width of 200px and add 20px padding, the total rendered width becomes 240px. With border-box, the padding and border are included inside the 200px width. Modern developers apply this globally:

Global Box-Sizing Reset
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

/* Card with explicit padding and border */
.card {
  width: 320px;
  padding: 24px;
  border: 1px solid var(--cl-line);
  margin-bottom: 24px;
  background: var(--cl-surface);
}

Display Properties: block (starts on new line, takes full width), inline (flows with text, ignores top/bottom margins), inline-block (flows inline but respects width/height), and none (completely removes from document flow).

كل عنصر يظهر على الشاشة في المتصفح يتم تمثيله كصندوق مستطيل. نموذج الصندوق (CSS Box Model) هو الهيكل الذي يحدد أبعاد وهوامش كل عنصر عبر أربع طبقات متداخلة:

  1. المحتوى (Content): النص أو الصورة المعروضة.
  2. الحشو الداخلي (Padding): المساحة الشفافة بين المحتوى وحدود العنصر.
  3. الحدود (Border): الإطار المحيط بالحشو والمحتوى.
  4. الهامش الخارجي (Margin): المساحة الشفافة الخارجية التي تفصل العنصر عن العناصر المجاورة.

أهم قاعدة في CSS الحديث: box-sizing: border-box

افتراضياً، تحسب CSS الأبعاد وفق content-box، أي إذا حددت عرض 200 بكسل مع حشو 20 بكسل، سيصبح العرض الفعلي 240 بكسل مما يكسر التخطيط. باستخدام border-box، يتم احتساب الحشو والإطار ضمن العرض الإجمالي المحدد:

تصفير قياس الصناديق العام
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

.card {
  width: 320px;
  padding: 24px;
  border: 1px solid var(--cl-line);
  margin-bottom: 24px;
  background: var(--cl-surface);
}

أنواع العرض (Display): block (يأخذ السطر كاملاً), inline (يتدفق بجانب النصوص ولا يقبل هوامش علوية), inline-block (يتدفق أفقياً مع قبول أبعاد محددة), وnone (إخفاء العنصر تماماً من شجرة المستند).

Lesson 4 — Colors, Backgrounds & Modern Gradients

Design

الدرس 4 — الألوان والخلفيات والتدرجات اللونية الحديثة

تصميم

Colors create emotion, brand identity, and visual hierarchy. In CSS3, you have multiple formats to declare colors with complete alpha-channel transparency control:

  • Hexadecimal: #2dd4bf or 8-digit hex with alpha #2dd4bf80 (50% opacity).
  • RGB / RGBA: rgb(45 212 191 / 0.8) using modern comma-free syntax.
  • HSL: hsl(172deg 66% 50%) (Hue, Saturation, Lightness — easiest for creating color palettes).

Gradients & Background Mastery:

Advanced Backgrounds & Gradients
/* Subtle dark teal linear gradient */
.hero-banner {
  background: linear-gradient(135deg, #020617 0%, #0f172a 50%, #115e59 100%);
  color: #ffffff;
  padding: 60px 40px;
  border-radius: 16px;
}

/* Background image with overlay and cover */
.card-header {
  background-image: linear-gradient(rgba(2, 6, 23, 0.7), rgba(2, 6, 23, 0.9)),
                    url('cover.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
Accessibility Rule: Ensure your text color has at least a 4.5:1 contrast ratio against the background (WCAG AA standard) for optimal readability.

الألوان تصنع الهوية البصرية وتحدد التراتبية للأعين. تدعم CSS3 صيغاً متعددة لتعريف الألوان مع التحكم الكامل في الشفافية (Alpha Channel):

  • السداسي عشري (Hex): #2dd4bf، أو بصيغة 8 خانات للشفافية #2dd4bf80.
  • RGB / RGBA: rgba(45, 212, 191, 0.8) لدمج نسب الأحمر والأخضر والأزرق مع الشفافية.
  • HSL: hsl(172, 66%, 50%) (تدرج اللون، التشبع، الإضاءة) وهي الأسهل في إنشاء تدرجات متناسقة.
تدرجات لونية وخلفيات حديثة
/* تدرج خطي متناسق */
.hero-banner {
  background: linear-gradient(135deg, #020617 0%, #0f172a 50%, #115e59 100%);
  color: #ffffff;
  padding: 60px 40px;
  border-radius: 16px;
}

/* صورة خلفية مع طبقة تظليل للحفاظ على وضوح النص */
.card-header {
  background-image: linear-gradient(rgba(2, 6, 23, 0.7), rgba(2, 6, 23, 0.9)),
                    url('cover.jpg');
  background-size: cover;
  background-position: center;
}
معيار إمكانية الوصول: حافظ دائماً على تباين لوني لا يقل عن 4.5:1 بين النص والخلفية لضمان سهولة القراءة لجميع الزوار.

Lesson 5 — Modern Web Typography & Font Engineering

Typography

الدرس 5 — الخطوط والطباعة الرقمية الحديثة (Typography)

طباعة وخطوط

Typography accounts for more than 90% of user interface communication. Clean typography makes your content enjoyable and effortless to read.

Units of Typography:

  • rem (Root EM): Scaled relative to the root <html> font size (usually 16px). Highly accessible because it respects user browser font preferences. (Recommended for all font sizes and spacings).
  • em: Scaled relative to the parent element's font size. Great for self-contained components.
  • px: Absolute pixels. Fixed, but does not scale if visually impaired users increase default browser zoom.
Modern Typography System
/* Base typography configuration */
html {
  font-size: 16px; /* 1rem = 16px */
}

body {
  font-family: 'Cairo', 'Outfit', system-ui, sans-serif;
  line-height: 1.7; /* Optimum line readability */
  color: var(--cl-text);
}

h1 {
  font-size: 2.5rem; /* 40px */
  font-weight: 800;
  letter-spacing: -0.02em;
  margin-bottom: 1rem;
}

p {
  font-size: 1.05rem;
  margin-bottom: 1.25rem;
  max-width: 70ch; /* Optimal line length: 60-75 characters */
}
Pro Tip: Limit line lengths to 60ch - 75ch (characters) for body text using max-width. Excessively long lines cause eye fatigue and lower reading retention.

تشكل النصوص أكثر من 90% من واجهات المستخدم على الويب. الطباعة المتقنة تجعل القراءة تجربة ممتعة ومريحة لعين الزائر.

وحدات قياس الخطوط الحديثة:

  • rem: تعتمد على حجم خط الجذر <html> (الافتراضي 16px). الخيار الأفضل لإمكانية الوصول واحترام إعدادات تكبير المتصفح لدى المستخدم.
  • em: تعتمد على حجم خط العنصر الأب المباشر. مفيدة للأزرار والمكونات المعزولة.
  • px: بكسل ثابت، لا يراعي تفضيلات المتصفح إذا قام المستخدم بتكبير الخط الأساسي.
منظومة خطوط احترافية
html {
  font-size: 16px; /* 1rem = 16px */
}

body {
  font-family: 'Cairo', system-ui, sans-serif;
  line-height: 1.8; /* تباعد مريح للأسطر */
}

h1 {
  font-size: 2.25rem;
  font-weight: 800;
  margin-bottom: 1rem;
}

p {
  font-size: 1.05rem;
  max-width: 70ch; /* طول السطر المثالي للقراءة */
}
نصيحة ذهبية: اجعل أقصى عرض للفقرة max-width: 70ch لكي لا يمتد السطر عبر الشاشات الكبيرة فيرهق عين القارئ.

Lesson 6 — Flexbox Architecture — One-Dimensional Layouts

Essential Tool

الدرس 6 — تخطيط فليكس بوكس (Flexbox) أحادي البعد

أداة محورية

CSS Flexible Box Layout (Flexbox) is the industry standard for distributing space and aligning items along a single axis (either row or column). It solved decades of layout headaches like vertical centering and equal-height columns.

Container Properties:

  • display: flex;: Activates flex context on direct children.
  • flex-direction: row | column;: Sets the main axis.
  • justify-content: flex-start | center | space-between | space-around;: Aligns along the main axis.
  • align-items: stretch | center | flex-start | flex-end;: Aligns along the cross axis (vertical in row mode).
  • gap: 16px;: Native spacing between items (no hacky margins!).
  • flex-wrap: wrap;: Allows items to break into new lines on smaller screens.
Real-World Flexbox Navbar & Card Row
/* Perfectly centered navbar */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px 32px;
  background: var(--cl-surface);
}

.nav-links {
  display: flex;
  gap: 20px;
  list-style: none;
}

/* Centering any element vertically & horizontally */
.center-box {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 200px;
}
Flex items tip: Use flex: 1; on a child to make it automatically expand and fill all available remaining space.

Flexbox (الصندوق المرن) هو النظام الأساسي لتوزيع العناصر والمحاذاة التلقائية على طول محور واحد (إما أفقياً كصف أو عمودياً كعمود). حل فليكس بوكس مشكلات قديمة مثل المحاذاة العمودية في الوسط وتساوي ارتفاعات البطاقات.

أهم خصائص حاوية Flexbox:

  • display: flex; لتفعيل النظام على العناصر الأبناء مباشرة.
  • flex-direction: row | column; لتحديد اتجاه المحور الرئيسي.
  • justify-content: space-between | center; لتوزيع العناصر على المحور الرئيسي.
  • align-items: center; لمحاذاة العناصر على المحور الثانوي (عمودياً).
  • gap: 16px; لترك مسافات متساوية بين العناصر دون الحاجة لهوامش يدوية.
  • flex-wrap: wrap; للسماح للعناصر بالانتقال لسطر جديد عند ضيق الشاشة.
شريط تنقل ومحاذاة بـ Flexbox
/* شريط تنقل متناسق */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px 32px;
  background: var(--cl-surface);
}

.nav-links {
  display: flex;
  gap: 20px;
  list-style: none;
}

/* توسيط كامل عمودياً وأفقياً */
.center-box {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 200px;
}
نصيحة فليكس: كتابة flex: 1; على العنصر الابن تجعله يتمدد تلقائياً لملء أي مساحة شاغرة متاحة.

Lesson 7 — CSS Grid — Two-Dimensional Modern Layouts

Advanced

الدرس 7 — شبكة CSS Grid — التخطيطات ثنائية الأبعاد

متقدم

While Flexbox is designed for 1-dimensional layouts (a row OR a column), CSS Grid is built from the ground up for 2-dimensional layouts (rows AND columns simultaneously). It is the most powerful layout engine ever built into the web platform.

The Magic of repeat(), auto-fit, and minmax():

With CSS Grid, you can create fully responsive card grids that automatically calculate the number of columns without writing a single media query:

Ultra-Responsive Auto-Fitting Grid
/* Zero-media-query responsive card layout */
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 24px;
}

/* 12-Column Classic Layout System */
.page-layout {
  display: grid;
  grid-template-columns: 280px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
  gap: 20px;
}

Grid Template Areas: Define your layout visually using ASCII-like declarations:

Grid Template Areas
.dashboard {
  display: grid;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  grid-template-columns: 240px 1fr;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

بينما يعمل Flexbox في بعد واحد (صف أو عمود)، صُمم نظام CSS Grid لإدارة التخطيطات ثنائية الأبعاد (صفوف وأعمدة معاً في آن واحد). وهو أقوى محرك تخطيط متوفر في متصفحات الويب الحديثة.

معادلة الشبكة التلقائية السحرية: auto-fit مع minmax()

تستطيع عبر سطر واحد بناء شبكة بطاقات مستجيبة تتكيف مع جميع الشاشات تلقائياً دون كتابة استعلام وسائط (Media Query) واحد:

شبكة بطاقات فائقة الاستجابة تلقائياً
/* تتكيف الأعمدة تلقائياً حسب عرض الشاشة */
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 24px;
}

/* تخطيط صفحة ثنائي الأعمدة */
.page-layout {
  display: grid;
  grid-template-columns: 280px 1fr;
  gap: 20px;
}

المناطق المحددة (Grid Template Areas): تسمح برسم هيكل الصفحة بتسميات واضحة ومباشرة مثل header و sidebar و main و footer.

Lesson 8 — Responsive Design, Media Queries & Fluid Units

Industry Standard

الدرس 8 — التصميم المستجيب (Responsive) ووحدات القياس المرنة

معيار عالمي

More than 60% of all web traffic comes from mobile devices. Responsive Web Design (RWD) ensures your website looks beautiful and functions smoothly across phones, tablets, laptops, and ultra-wide desktops.

The Mobile-First Strategy: Write your default CSS for mobile screens without media queries. Then, use @media (min-width: ...) to progressively add complexity as screen width expands. This improves mobile performance and simplifies CSS logic.

Mobile-First Media Query Breakpoints
/* 1. Mobile Default (Base styles) */
.container {
  padding: 16px;
  flex-direction: column;
}

/* 2. Tablet (min-width: 768px) */
@media (min-width: 768px) {
  .container {
    padding: 32px;
    flex-direction: row;
  }
}

/* 3. Desktop (min-width: 1024px) */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}

/* Fluid Typography with clamp() */
h1 {
  /* clamp(min, preferred, max) */
  font-size: clamp(1.75rem, 4vw + 1rem, 3.5rem);
}
Modern Magic: clamp() allows font sizes, paddings, and margins to fluidly interpolate between minimum and maximum boundaries based on viewport width without rigid breakpoints!

أكثر من 60% من زيارات الويب اليوم تأتي من الهواتف الذكية. التصميم المستجيب (Responsive Design) يضمن أن موقعك يظهر بجمالية وانسيابية كاملة على مختلف الأجهزة: الهواتف، الأجهزة اللوحية، والشاشات الكبيرة.

استراتيجية الجوال أولاً (Mobile-First): تبدأ بكتابة الأنماط الأساسية لشاشات الهواتف مباشرة، ثم تستخدم استعلامات @media (min-width: ...) لإضافة التعديلات تدريجياً مع اتساع الشاشة. هذا يحقق سرعة أعلى وكوداً أنظف.

نقاط التوقف (Breakpoints) بمعيار Mobile-First
/* الأنماط الافتراضية للهواتف */
.container {
  padding: 16px;
  flex-direction: column;
}

/* الأجهزة اللوحية (ابتداء من 768px) */
@media (min-width: 768px) {
  .container {
    padding: 32px;
    flex-direction: row;
  }
}

/* الشاشات الكبيرة (ابتداء من 1024px) */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}

/* خط مرن يتناسب تلقائياً مع الشاشة */
h1 {
  font-size: clamp(1.75rem, 4vw + 1rem, 3.5rem);
}
خاصية clamp السحرية: تتيح للدالة clamp(min, val, max) تحديد حد أدنى وحد أقصى لحجم الخط أو الهوامش مع تغير انسيابي مستمر بحسب عرض الشاشة.

Lesson 9 — Transforms, Transitions & Keyframe Animations

Interaction

الدرس 9 — التحولات والانتقالات والرسوم المتحركة (Animations)

حركة وتفاعل

Micro-interactions and smooth animations transform a static website into a tactile, premium application. CSS provides two powerful systems for motion: Transitions (state changes) and Keyframe Animations (complex, looping sequences).

1. Transitions & Hardware-Accelerated Transforms:

Always animate transform (translate, scale, rotate) and opacity. These properties are processed directly by the GPU, ensuring smooth 60fps animations without causing browser reflow or repaint lag.

Smooth Button & Keyframe Animation
/* Interactive Card Hover with Transition */
.card {
  transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1),
              box-shadow 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.card:hover {
  transform: translateY(-6px);
  box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.3);
}

/* Infinite Pulse Animation with @keyframes */
@keyframes pulseGlow {
  0%, 100% {
    transform: scale(1);
    opacity: 0.8;
  }
  50% {
    transform: scale(1.08);
    opacity: 1;
  }
}

.badge-live {
  animation: pulseGlow 2s infinite ease-in-out;
}
Performance Rule: Never animate properties like width, height, top, or left. They force CPU layout calculations. Use transform: translate() or scale() instead.

تمنح الانتقالات والرسوم المتحركة الموقع طابعاً حيوياً وسلساً يجذب المستخدمين. توفر CSS وسيلتين رئيسيتين: الانتقالات (Transitions) للتفاعل اللحظي، ورسوم الإطارات الرئيسية (@keyframes) للحركات المعقدة والمتكررة.

قاعدة الأداء العالي لمعالج الرسومات (GPU):

احرص دائماً على تحريك خاصيتي transform (التحريك وتغيير الحجم والدوران) و opacity (الشفافية). يتم معالجة هاتين الخاصيتين مباشرة بواسطة كارت الشاشة (GPU) مما يضمن سرعة 60 إطاراً في الثانية دون ثقل أو تجميد.

كود انتقال وحركة متكاملة
/* تأثير صعود البطاقة عند التمرير */
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-6px);
  box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.3);
}

/* حركة نبض متكررة */
@keyframes pulseGlow {
  0%, 100% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.06);
  }
}

.badge-live {
  animation: pulseGlow 2s infinite ease-in-out;
}
تحذير أداء: تجنب تحريك width أو height أو margin لأنها تستهلك المعالج. استعض عنها بـ transform: scale() أو translate().

Lesson 10 — CSS Custom Properties, Dark Mode & Architecture

Production Architecture

الدرس 10 — متغيرات CSS، الوضع الليلي، والهيكلة الاحترافية

معمارية الإنتاج

CSS Custom Properties (Variables) allow you to store values (colors, spacing, font sizes) centrally and reuse them throughout your stylesheet. Unlike preprocessors (SASS/LESS), native CSS variables are dynamic and update live at runtime via JavaScript or media queries.

Building a Production Dark Mode System:

Complete Theme Architecture with CSS Variables
/* 1. Light Theme Tokens (Default) */
:root {
  --cl-bg: #f8fafc;
  --cl-surface: #ffffff;
  --cl-text: #0f172a;
  --cl-muted: #64748b;
  --cl-brand: #0f766e;
  --cl-line: #e2e8f0;
}

/* 2. Dark Theme Tokens */
[data-theme="dark"] {
  --cl-bg: #020617;
  --cl-surface: #0f172a;
  --cl-text: #f8fafc;
  --cl-muted: #94a3b8;
  --cl-brand: #2dd4bf;
  --cl-line: #1e293b;
}

/* 3. Universal Components consume tokens */
body {
  background-color: var(--cl-bg);
  color: var(--cl-text);
  transition: background-color 0.3s ease, color 0.3s ease;
}

.card {
  background: var(--cl-surface);
  border: 1px solid var(--cl-line);
}

CSS Architecture Best Practices (BEM Methodology):

  • Block: Standalone entity (.btn, .card).
  • Element: Part of a block that has no standalone meaning (.card__title, .card__body).
  • Modifier: Flag that changes appearance or behavior (.btn--primary, .card--featured).
Pro Architect Tip: Maintain a tokens.css or variables.css file. When your brand colors change, you update one single line of code instead of searching across thousands of lines!

متغيرات CSS (Custom Properties) تتيح لك تخزين القيم المتكررة (مثل درجات الألوان، قياسات الهوامش، وأنواع الخطوط) في مكان مركزي وإعادة استخدامها عبر الموقع. وعلى عكس معالجات SASS القديمة، متغيرات CSS الأصلية ديناميكية وتستجيب لحظياً للتغييرات عبر JavaScript.

بناء نظام الوضع الليلي (Dark Mode) الاحترافي:

معمارية متكاملة للثيمات بالمتغيرات
/* المتغيرات الافتراضية (الوضع الفاتح) */
:root {
  --cl-bg: #f8fafc;
  --cl-surface: #ffffff;
  --cl-text: #0f172a;
  --cl-brand: #0f766e;
  --cl-line: #e2e8f0;
}

/* متغيرات الوضع الليلي الداكن */
[data-theme="dark"] {
  --cl-bg: #020617;
  --cl-surface: #0f172a;
  --cl-text: #f8fafc;
  --cl-brand: #2dd4bf;
  --cl-line: #1e293b;
}

/* تطبيق المتغيرات على العناصر */
body {
  background-color: var(--cl-bg);

  transition: background-color 0.3s ease;
}

.card {
  background: var(--cl-surface);
  border: 1px solid var(--cl-line);
}

منهجية BEM لتنظيم الكلاسات: البلوك .card، العنصر .card__title، والمعدل .btn--primary. تساعدك هذه التسميات في تجنب تداخل التنسيقات عند كبر حجم المشاريع البرمجية.
