Chapter 1: Relational Design (Normalization)

Database design is about reducing redundancy. Learn 1NF, 2NF, and 3NF to build scalable and consistent data structures.

Pro Rule: If you find yourself duplicating data in multiple rows, you probably need a new table and a foreign key.

Chapter 2: Advanced JOIN Strategies

JOINs are the heart of SQL. Understanding the difference between LEFT JOIN and INNER JOIN is crucial for accurate reports.

/* Find customers who have NEVER placed an order */
SELECT customers.name, orders.order_id
FROM customers
LEFT JOIN orders ON customers.id = orders.customer_id
WHERE orders.order_id IS NULL;

Chapter 3: Query Optimization & Indexing

A query that takes 10 seconds is a bug. Learn how Indexes speed up SELECT but can slow down INSERT. Master the EXPLAIN command.

/* Create a covering index for performance */
CREATE INDEX idx_user_login 
ON users (email, password_hash);

/* Analyze performance */
EXPLAIN SELECT * FROM users WHERE email = 'test@site.com';

Chapter 4: Analytical Window Functions

Window functions like OVER(), RANK(), and PARTITION BY allow you to perform calculations across a set of rows related to the current row.

/* Rank products by sales within each category */
SELECT 
  name, 
  category, 
  sales,
  RANK() OVER(PARTITION BY category ORDER BY sales DESC) as rank
FROM products;
