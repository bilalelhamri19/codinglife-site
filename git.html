Chapter 1: Branching Strategies

In a team, everyone can't work on the same branch. Learn Gitflow and GitHub Flow to manage features, releases, and hotfixes safely.

Pro Rule: Never commit directly to main. Always use feature branches and Pull Requests.

Chapter 2: Rebase vs Merge

Keep your history clean. Learn when to use git rebase to maintain a linear history and when to use git merge to preserve the context of feature integration.

/* Syncing your branch with main using Rebase */
git checkout feature-branch
git fetch origin
git rebase origin/main

/* If conflicts occur */
git status
git add [files]
git rebase --continue

Chapter 3: The Stash & Cherry-pick

Need to switch branches but not ready to commit? git stash is your best friend. Found a bug fix in another branch? git cherry-pick it into yours.

/* Save temporary work */
git stash save "Working on login logic"

/* Switch branches, then come back */
git stash pop

/* Pick a specific commit from another branch */
git cherry-pick [commit-hash]

Chapter 4: Reflog - The Safety Net

Deleted a branch by mistake? Messed up a rebase? git reflog keeps a record of every move you made, allowing you to travel back in time to any state.
