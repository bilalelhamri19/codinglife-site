Chapter 1: Mastering Hooks & Lifecycle

Hooks are the heart of functional React. Learn how to manage state and side effects with precision to avoid unnecessary re-renders.

/* Pro useEffect with Cleanup */
useEffect(() => {
  const socket = connectToWS();
  
  return () => {
    // Critical: Clean up to prevent memory leaks
    socket.disconnect();
  };
}, []); // Empty array means run once on mount

Chapter 2: Performance (Memoization)

In large apps, performance is key. Use useMemo for expensive calculations and useCallback to prevent children from re-rendering.

const expensiveVal = useMemo(() => {
  return complexCalculation(data);
}, [data]);

const handleAction = useCallback(() => {
  doSomething(expensiveVal);
}, [expensiveVal]);

Chapter 3: Advanced State Management

When does "Prop Drilling" become a problem? Learn when to use useContext for simple global state and when to reach for tools like Zustand or Redux Toolkit.
