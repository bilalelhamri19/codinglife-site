The Golden Rule: Strict Equality (===) vs Loose Equality (==)

Always use strict equality === and strict inequality !==. Loose equality (==) performs unexpected type coercion behind the scenes, leading to bizarre bugs:

Never use ==: Using === protects your code from unpredictable edge cases and keeps business logic deterministic.

Functions are the primary building blocks of programs. They bundle reusable pieces of logic that accept inputs (parameters) and return outputs.

ES6 Arrow Functions: Arrow functions provide a cleaner, more concise syntax and automatically bind the lexical this value from their surrounding context.

Function Declarations vs Arrow Functions
// 1. Traditional Function Declaration
function calculateDiscount(price, discountPercent = 10) {
  return price - (price * (discountPercent / 100));
}

// 2. Modern Arrow Function
const calculateTax = (subtotal, rate = 0.20) => subtotal * rate;

// 3. Arrow Function with implicit return (single line)
const square = num => num * num;

console.log(calculateDiscount(100, 15)); // 85
console.log(calculateTax(100));          // 20

Arrays hold ordered lists of items. Modern JavaScript replaces traditional loops with functional, declarative higher-order methods that don't mutate original data:

  • map(): Transforms every item in an array and returns a brand-new array.
  • filter(): Returns a new array with items that satisfy a truth condition.
  • reduce(): Accumulates array items into a single final value (e.g. total sum).
  • find(): Returns the first item matching a condition.
