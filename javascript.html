Lesson 1 — Introduction to JavaScript & The Browser Runtime

Foundations

الدرس 1 — مقدمة في JavaScript وبيئة تشغيل المتصفح

الأساسيات

JavaScript is the universal programming language of the World Wide Web. While HTML provides the skeleton and CSS provides the skin and styling, JavaScript represents the brain and nervous system — handling interactivity, calculations, network requests, and dynamic UI updates.

JavaScript executes inside an engine embedded within the browser (such as Google's V8 in Chrome and Node.js, SpiderMonkey in Firefox, or JavaScriptCore in Safari). It is a high-level, single-threaded, garbage-collected language equipped with a non-blocking event loop.

Connecting JavaScript to HTML:

The Correct Way to Link JavaScript
<!-- Always link with 'defer' in the head for optimum performance -->
<script src="app.js" defer></script>

<!-- 'defer' ensures HTML parses first, then script runs in order -->
Pro Tip: Open your browser Developer Tools anytime by pressing F12 or Ctrl+Shift+I (Cmd+Option+I on Mac) and switch to the Console tab. You can test JS statements in real time!

JavaScript (جافاسكريبت) هي لغة البرمجة العالمية للويب. إذا كان HTML هو الهيكل العظمي وCSS هو المظهر الخارجي والألوان، فإن جافاسكريبت هي العقل والجهاز العصبي للموقع — تدير التفاعل، الحسابات، طلبات الخادم (APIs)، وتحديث الواجهات لحظياً دون إعادة تحميل الصفحة.

تعمل جافاسكريبت داخل محركات فائقة السرعة مدمجة في المتصفحات (مثل محرك V8 في كروم وNode.js، أو SpiderMonkey في فايرفوكس). وهي لغة عالية المستوى تعتمد على حلقة الأحداث (Event Loop) لمعالجة المهام بكفاءة دون تجميد واجهة المستخدم.

الطريقة النموذجية لربط كود جافاسكريبت
<!-- استخدم دائماً السمة defer داخل وسم head -->
<script src="app.js" defer></script>

<!-- defer تسمح بتحميل الصفحة فوراً دون انتظار تنزيل ملف السكريبت -->
نصيحة للمبتدئين: اضغط على F12 في أي متصفح وانتقل إلى لسان Console لتجربة كتابة وتنفيذ أكواد جافاسكريبت مباشرة!

Lesson 2 — Variables (let, const) & Data Types Deep Dive

Core Logic

الدرس 2 — المتغيرات (let, const) وأنواع البيانات بالتفصيل

منطق أساسي

Variables are containers for storing data values. In modern JavaScript (ES6+), we use two keywords:

  • const: For variables whose reference will not be reassigned. (Default choice in 90% of code).
  • let: For variables that need to change over time (e.g. counters, loop iterators).
  • Avoid var: It has function-level scope and variable hoisting bugs that cause hard-to-find defects.

JavaScript Data Types:

  1. Primitive Types (Immutable): string, number, boolean, null, undefined, BigInt, Symbol.
  2. Reference Types: Object, Array, Function.
Declaring Variables & Template Literals
const platformName = "Coding Life";
let activeStudents = 1540;
const isFreeForever = true;

// Template literals with backticks `` allow seamless string interpolation
const welcomeMessage = `Welcome to ${platformName}! Total learners: ${activeStudents}.`;
console.log(welcomeMessage);

// Checking types
console.log(typeof platformName); // "string"
console.log(typeof isFreeForever); // "boolean"

المتغيرات هي حاويات لتخزين البيانات والقيم. في جافاسكريبت الحديثة (معايير ES6+)، نستخدم كلمتين رئيسيتين للتصريح عن المتغيرات:

  • const: للمتغيرات الثابتة التي لن يُعاد تعيينها (الخيار الافتراضي في أغلب الأكواد).
  • let: للمتغيرات القابلة للتغير لاحقاً (مثل العدادات وقيم المدخلات).
  • تجنب استخدام var القديمة: لأنها تعاني من مشاكل في نطاق الرؤية وتسبب أخطاء خفية.

أنواع البيانات الأساسية: النصوص (string)، الأرقام (number)، القيم المنطقية (boolean)، والقيم الفارغة (null و undefined).

التصريح عن المتغيرات وسلاسل النصوص الذكية
const platformName = "Coding Life";
let activeStudents = 1540;
const isFree = true;

// استخدام علامة التنصيص المائلة للدمج السلس (Template Literals)
const message = `مرحباً بك في ${platformName}! عدد المتعلمين: ${activeStudents}`;
console.log(message);

Lesson 3 — Operators, Comparisons & Type Coercion

Clean Code

الدرس 3 — المعاملات البرمجية والتحقق ومطابقة الأنواع

كود نظيف

Operators perform operations on variables and values: arithmetic (+, -, *, /, %), assignment (=, +=), comparison, and logical evaluations.

The Golden Rule: Strict Equality (===) vs Loose Equality (==)

Always use strict equality === and strict inequality !==. Loose equality (==) performs unexpected type coercion behind the scenes, leading to bizarre bugs:

Strict Equality vs Type Coercion Trap
// Loose equality allows unsafe type conversions:
console.log(5 == "5");  // true (Dangerous!)
console.log(0 == false); // true (Dangerous!)

// Strict equality checks value AND data type:
console.log(5 === "5");  // false (Correct & Safe)
console.log(5 === 5);    // true

// Modern Nullish Coalescing (??) - returns right side only if null or undefined
const userNickname = null;
const displayName = userNickname ?? "Guest Developer"; // "Guest Developer"
Never use ==: Using === protects your code from unpredictable edge cases and keeps business logic deterministic.

تستخدم المعاملات الرياضية والمنطقية لإجراء العمليات على المتغيرات: الجمع، الطرح، المقارنة، والتحقق المنطقي.

القاعدة الذهبية: المطابقة الصارمة === مقابل المطابقة التقريبية ==

استخدم دائماً المطابقة التامة ===. المطابقة القديمة == تقوم بتحويل نوع البيانات قسراً مما يسبب أخطاء برمجية خادعة:

الفرق بين المطابقة الصارمة والعادية
// المطابقة العادية خطرة:
console.log(5 == "5");   // true (خطأ منطقي!)

// المطابقة الصارمة تتحقق من القيمة ونوع البيانات معاً:
console.log(5 === "5");  // false (صحيح وآمن)

// المعامل الحديث ?? (Nullish Coalescing)
const username = null;
const greeting = username ?? "زائر متميز"; // يعطي القيمة البديلة عند غياب القيمة

Lesson 4 — Control Flow, Conditionals & Modern Loops

Control Flow

الدرس 4 — التحكم في التدفق والشروط وحلقات التكرار الحديثة

تدفق التنفيذ

Conditionals allow your code to make decisions and execute different paths based on conditions. Loops let you repeat logic efficiently over collections of data.

Modern Conditionals & for...of Loops
const score = 88;

// If / Else If Ladder
if (score >= 90) {
  console.log("Grade: Outstanding!");
} else if (score >= 75) {
  console.log("Grade: Proficient");
} else {
  console.log("Keep practicing!");
}

// Ternary Operator for concise inline decisions:
const status = score >= 60 ? "Passed" : "Needs Review";

// Modern for...of loop for clean array iteration
const technologies = ["HTML5", "CSS3", "JavaScript", "Python"];
for (const tech of technologies) {
  console.log(`Learning: ${tech}`);
}
Pro Tip: Prefer for...of loops when iterating arrays. It is cleaner and avoids manual counter indexing bugs common with traditional for (let i = 0; ...).

الجمل الشرطية تمكّن برنامجك من اتخاذ القرارات وتنفيذ تعليمات معينة بناءً على شروط محددة. وتتيح لك حلقات التكرار (Loops) معالجة مجموعات البيانات بسهولة وسرعة.

الشروط وحلقة for...of الحديثة
const score = 85;

// الجملة الشرطية if/else
if (score >= 90) {
  console.log("النتيجة: ممتاز");
} else if (score >= 70) {
  console.log("النتيجة: جيد جداً");
} else {
  console.log("واصل المحاولة والممارسة");
}

// التكرار الحديث الأنيق for...of على المصفوفات
const skills = ["HTML5", "CSS3", "JavaScript", "Python"];
for (const skill of skills) {
  console.log(`تعلم مهارة: ${skill}`);
}

Lesson 5 — Functions, Arrow Functions & Scope Closures

Functions

الدرس 5 — الدوال العادية والدوال السهمية (Arrow Functions) ونطاق المتغيرات

دوال ونطاقات

Functions are the primary building blocks of programs. They bundle reusable pieces of logic that accept inputs (parameters) and return outputs.

ES6 Arrow Functions: Arrow functions provide a cleaner, more concise syntax and automatically bind the lexical this value from their surrounding context.

Function Declarations vs Arrow Functions
// 1. Traditional Function Declaration
function calculateDiscount(price, discountPercent = 10) {
  return price - (price * (discountPercent / 100));
}

// 2. Modern Arrow Function
const calculateTax = (subtotal, rate = 0.20) => subtotal * rate;

// 3. Arrow Function with implicit return (single line)
const square = num => num * num;

console.log(calculateDiscount(100, 15)); // 85
console.log(calculateTax(100));          // 20
console.log(square(5));                 // 25

Understanding Closures: A closure is created when an inner function remembers and maintains access to variables declared in its outer parent scope, even after the outer function has finished executing. Closures enable private variables and data encapsulation.

الدوال (Functions) هي اللبنات الأساسية لأي تطبيق. تقوم بتجميع مجموعة من الأوامر القابلة لإعادة الاستخدام، تستقبل مدخلات وترجع مخرجات محسوبة.

الدوال السهمية (Arrow Functions): أحدثت ثورة في جافاسكريبت باختصارها للكود وتسهيل كتابة الدوال المصغرة والمضمنة.

مقارنة بين الدوال العادية والدوال السهمية الحديثة
// دالة عادية مع قيمة افتراضية للمعامل
function calculateDiscount(price, discount = 10) {
  return price - (price * (discount / 100));
}

// دالة سهمية حديثة ومختصرة
const calculateTax = (amount, rate = 0.20) => amount * rate;

// استدعاء الدوال
console.log(calculateDiscount(200, 20)); // 160
console.log(calculateTax(100));          // 20

Lesson 6 — Arrays & Modern High-Order Methods (map, filter, reduce)

Data Mastery

الدرس 6 — المصفوفات والدوال العليا الحديثة (map, filter, reduce)

إدارة البيانات

Arrays hold ordered lists of items. Modern JavaScript replaces traditional loops with functional, declarative higher-order methods that don't mutate original data:

  • map(): Transforms every item in an array and returns a brand-new array.
  • filter(): Returns a new array with items that satisfy a truth condition.
  • reduce(): Accumulates array items into a single final value (e.g. total sum).
  • find(): Returns the first item matching a condition.
Declarative Array Processing
const courses = [
  { id: 1, title: "HTML5", hours: 4, level: "Beginner" },
  { id: 2, title: "CSS3", hours: 5, level: "Intermediate" },
  { id: 3, title: "JavaScript", hours: 6, level: "Advanced" },
  { id: 4, title: "Python", hours: 5, level: "Beginner" }
];

// 1. Filter: Get only Beginner courses
const beginnerCourses = courses.filter(c => c.level === "Beginner");

// 2. Map: Extract an array of course titles
const courseTitles = courses.map(c => c.title);

// 3. Reduce: Calculate total study hours across all courses
const totalHours = courses.reduce((sum, c) => sum + c.hours, 0);

console.log(courseTitles); // ["HTML5", "CSS3", "JavaScript", "Python"]
console.log(`Total Study Duration: ${totalHours} hours`); // 20 hours

تحتوي المصفوفات على قوائم مرتبة من البيانات. أحدثت الدوال العليا (High-Order Methods) ثورة برمجية حيث تتيح فلترة وتحويل وتجميع البيانات بأسلوب إعلاني نظيف دون تعديل المصفوفة الأصلية:

  • map(): لتحويل كل عنصر في المصفوفة وإرجاع مصفوفة جديدة بالنتائج.
  • filter(): لتصفية العناصر واستخراج ما يطابق الشرط فقط.
  • reduce(): لضغط عناصر المصفوفة وحساب قيمة نهائية واحدة (كالمجموع الكلي).
معالجة البيانات بـ map و filter و reduce
const courses = [
  { title: "HTML5", hours: 4, level: "Beginner" },
  { title: "CSS3", hours: 5, level: "Intermediate" },
  { title: "JavaScript", hours: 6, level: "Advanced" }
];

// استخراج العناوين فقط عبر map
const titles = courses.map(c => c.title);

// حساب إجمالي ساعات التعلم عبر reduce
const totalHours = courses.reduce((acc, c) => acc + c.hours, 0);

console.log(titles); // ["HTML5", "CSS3", "JavaScript"]
console.log(`المجموع: ${totalHours} ساعات`); // 15 ساعات

Lesson 7 — Objects, Destructuring & JSON Serialization

Data Structures

الدرس 7 — الكائنات (Objects)، التفكيك (Destructuring) وصيغة JSON

هياكل البيانات

Objects are key-value collections used to represent entities in real-world applications. Modern JavaScript introduces Destructuring and the Spread Operator (...) to work with objects effortlessly.

Object Destructuring, Spread & JSON
const developer = {
  name: "Bilal",
  role: "Full-Stack Engineer",
  skills: ["JS", "Python", "CSS"],
  location: "Morocco"
};

// 1. Destructuring: Unpack properties directly into variables
const { name, role, skills } = developer;
console.log(`${name} is a ${role}.`);

// 2. Spread Operator: Immutable cloning & merging
const updatedDeveloper = {
  ...developer,
  role: "Lead Architect",
  isAvailable: true
};

// 3. JSON Serialization (Converting for API exchange)
const jsonString = JSON.stringify(updatedDeveloper);
const parsedObj = JSON.parse(jsonString);
JSON Insight: JSON (JavaScript Object Notation) is the universal language of APIs across all programming languages (Python, Java, Go, PHP). JSON.stringify() encodes; JSON.parse() decodes.

الكائنات (Objects) هي مجموعات من أزواج المفاتيح والقيم (Key-Value) لتمثيل البيانات الحقيقية. توفر جافاسكريبت الحديثة خاصية التفكيك (Destructuring) ومعامل النشر (Spread Operator) لتسهيل التعامل مع الكائنات دون تكرار.

تفكيك الكائنات والتحويل إلى JSON
const user = {
  name: "بلال",
  role: "مطور برمجيات",
  experience: 5
};

// استخراج الخصائص مباشرة (Destructuring)
const { name, role } = user;
console.log(`${name} - ${role}`);

// استنساخ الكائن وتعديله بأمان دون المساس بالأصل
const updatedUser = { ...user, active: true };

// التحويل إلى صيغة JSON لتبادل البيانات مع السيرفر
const jsonData = JSON.stringify(updatedUser);
const backToObject = JSON.parse(jsonData);

Lesson 8 — DOM Selection & Real-Time UI Manipulation

DOM Mastery

الدرس 8 — التحكم في الـ DOM وتحديث واجهة المستخدم لحظياً

احتراف الـ DOM

The Document Object Model (DOM) is the tree representation of an HTML document in browser memory. JavaScript can read, modify, add, or delete any HTML element and CSS style dynamically.

Selecting & Modifying DOM Elements
// Selecting elements using CSS selector syntax
const heading = document.querySelector("#main-title");
const allCards = document.querySelectorAll(".lesson-card");

// Modifying text & attributes securely
heading.textContent = "Welcome to Modern JavaScript!";

// Managing CSS classes dynamically (preferred over inline styles)
heading.classList.add("highlight");
heading.classList.toggle("dark-mode");

// Creating and inserting new elements dynamically
const newBadge = document.createElement("span");
newBadge.className = "badge badge-pro";
newBadge.textContent = "New Lesson";
heading.appendChild(newBadge);
Security Reminder: Always prefer textContent over innerHTML when inserting user-supplied data to prevent Cross-Site Scripting (XSS) vulnerabilities.

شجرة الـ DOM هي البنية البرمجية لملف HTML داخل ذاكرة المتصفح. من خلالها تستطيع جافاسكريبت قراءة وتعديل وحذف أي عنصر وتغيير كلاسات الـ CSS فورياً.

تحديد العناصر وتعديلها بأمان
// تحديد العناصر باستخدام محددات CSS
const title = document.querySelector("h1");

// تعديل النص بأمان تام
title.textContent = "مرحباً بكم في كورس جافاسكريبت المحدث!";

// التحكم في كلاسات CSS
title.classList.add("active");
title.classList.toggle("theme-dark");

// إنشاء عناصر جديدة وإضافتها للصفحة
const badge = document.createElement("span");
badge.className = "badge badge-beginner";
badge.textContent = "درس جديد";
title.appendChild(badge);
أمان المعلومات: استخدم textContent بدلاً من innerHTML عند إدراج نصوص يدخلها المستخدمون لحماية موقعك من هجمات XSS الخبيثة.

Lesson 9 — Events, Form Handling & User Interaction

Interactivity

الدرس 9 — إدارة الأحداث ومعالجة النماذج وتفاعل المستخدم

تفاعل حي

Events notify code that something interesting occurred: a button click, a key press, a window resize, or a form submission. We register listeners using addEventListener.

Event Handling & Form Interception
const submitButton = document.querySelector("#submitBtn");
const searchInput = document.querySelector("#searchInput");
const contactForm = document.querySelector("#contactForm");

// 1. Click Event
submitButton.addEventListener("click", (event) => {
  console.log("Button clicked!");
});

// 2. Real-time Live Input Event
searchInput.addEventListener("input", (event) => {
  const query = event.target.value.toLowerCase();
  console.log(`Searching for: ${query}`);
});

// 3. Form Submission with preventDefault()
contactForm.addEventListener("submit", (event) => {
  event.preventDefault(); // Prevents page reload
  
  const formData = new FormData(contactForm);
  const email = formData.get("email");
  console.log(`Sending message for: ${email}`);
});
Event Delegation: Instead of attaching listeners to 100 individual buttons, attach a single listener to their parent container and inspect event.target. This optimizes performance significantly.

الأحداث (Events) هي إشارات يطلقها المتصفح عند قيام المستخدم بإجراء معين: نقر زر، كتابة في حقل إدخال، تحريك الفأرة، أو إرسال نموذج. نربط الأحداث بالدوال عبر addEventListener.

الاستماع للأحداث والتحكم في النماذج
const btn = document.querySelector("#myBtn");
const form = document.querySelector("#myForm");

// الاستماع للنقر
btn.addEventListener("click", (e) => {
  console.log("تم النقر على الزر بنجاح!");
});

// معالجة النماذج ومنع إعادة تحميل الصفحة
form.addEventListener("submit", (e) => {
  e.preventDefault(); // منع السلوك الافتراضي للمتصفح
  
  const inputVal = document.querySelector("#emailInput").value;
  console.log(`تم استلام البريد: ${inputVal}`);
});

Lesson 10 — Asynchronous JS — Promises, Async/Await & Fetch API

Production Level

الدرس 10 — البرمجة غير المتزامنة — الوعود، Async/Await وواجهة Fetch API

مستوى احترافي

Network requests (like fetching data from a database or API) take time. If JavaScript blocked execution while waiting, your entire webpage would freeze. Asynchronous JavaScript allows tasks to run in the background while keeping the UI responsive.

Modern Async/Await with the Fetch API:

Fetching Real Data with async/await and try/catch
async function loadGithubProfile(username) {
  try {
    const response = await fetch(`https://api.github.com/users/${username}`);
    
    // Check if HTTP request was successful (status 200-299)
    if (!response.ok) {
      throw new Error(`Profile not found (Status: ${response.status})`);
    }
    
    const data = await response.json();
    console.log(`User: ${data.name}, Public Repos: ${data.public_repos}`);
    return data;
  } catch (error) {
    console.error("Fetch failed:", error.message);
  } finally {
    console.log("Request finished.");
  }
}

// Storing data in browser localStorage
localStorage.setItem("userRole", "developer");
const savedRole = localStorage.getItem("userRole");
Congratulations: You now possess the complete foundational and modern JavaScript toolset required to build real interactive web applications!

جلب البيانات من الخوادم وواجهات الـ API يستغرق وقتاً. لكي لا تتجمد الصفحة أثناء الانتظار، تعتمد جافاسكريبت على البرمجة غير المتزامنة (Asynchronous) لتنفيذ المهام في الخلفية مع بقاء واجهة الموقع سريعة واستجابية.

استخدام Async/Await وواجهة Fetch الحديثة:

جلب بيانات حقيقية ومعالجة الأخطاء بـ try/catch
async function fetchUserData(username) {
  try {
    const response = await fetch(`https://api.github.com/users/${username}`);
    
    if (!response.ok) {
      throw new Error("تعذر العثور على المستخدم المطلوب");
    }
    
    const user = await response.json();
    console.log(`الاسم: ${user.name} | المستودعات: ${user.public_repos}`);
