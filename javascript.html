Arrow Functions & Lexical Scope

Arrow functions provide a concise syntax for writing functions. Unlike regular functions, they do not have their own this context.

دوال السهم والنطاق المعجمي

توفر دوال السهم (Arrow Functions) صيغة مختصرة لكتابة الدوال. على عكس الدوال العادية، فهي لا تملك سياق this الخاص بها.

Asynchronous JS & The Event Loop

JavaScript is single-threaded but handles asynchronous operations using the Event Loop. This ensures the user interface doesn't freeze while waiting for data.

جافا سكريبت غير المتزامنة و Event Loop

جافا سكريبت أحادية المسار ولكنها تتعامل مع العمليات غير المتزامنة باستخدام الـ Event Loop. هذا يضمن عدم تجميد واجهة المستخدم أثناء انتظار البيانات.
