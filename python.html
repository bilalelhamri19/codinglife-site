Python Basics & Philosophy

Python is a high-level, general-purpose programming language. Its design philosophy emphasizes code readability with the use of significant indentation.

One of the core tenets of Python is "The Zen of Python", which states that "Simple is better than complex."

أساسيات وفلسفة بايثون

بايثون هي لغة برمجة عالية المستوى ومتعددة الأغراض. تركز فلسفة تصميمها على سهولة قراءة الكود مع استخدام مسافات البادئة بشكل أساسي.

أحد المبادئ الأساسية لبايثون هو "The Zen of Python"، الذي ينص على أن "البسيط أفضل من المعقد".

Variables & Dynamic Typing

In Python, variables are essentially names that point to objects in memory. Unlike languages like C++ or Java, Python is dynamically typed.

المتغيرات والأنواع الديناميكية

في بايثون، المتغيرات هي في الأساس أسماء تشير إلى كائنات في الذاكرة. على عكس لغات مثل C++ أو Java، تتميز بايثون بأنها ديناميكية الأنواع.

OOP: Classes and Objects

Python is an object-oriented language. Classes allow you to bundle data and functionality together.

البرمجة كائنية التوجه: الفئات والكائنات

بايثون هي لغة موجهة للكائنات. تسمح لك الفئات (Classes) بتجميع البيانات والوظائف معاً في هيكل واحد.

Data Analysis with Pandas

Pandas is a fast, powerful, and flexible open-source data analysis tool. Its DataFrame structure allows you to handle tabular data with ease.

تحليل البيانات باستخدام Pandas

Pandas هي أداة تحليل بيانات مفتوحة المصدر سريعة وقوية ومرنة. تسمح لك بنية DataFrame الخاصة بها بالتعامل مع البيانات الجدولية بسهولة.
