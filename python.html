Lesson 2 — Variables, Dynamic Typing & User Input

Core Syntax

الدرس 2 — المتغيرات، الأنواع الديناميكية، ومدخلات المستخدم

قواعد أساسية

Python is dynamically typed. You don't need to declare variable types explicitly — Python infers the type automatically at runtime.

Primary Data Types:

  • int: Whole numbers (e.g. 42, -7).
  • float: Decimal numbers (e.g. 3.14159).
  • str: Text strings enclosed in single or double quotes.
  • bool: Boolean values (True or False with capitalized first letters).
Variables, f-strings, and Type Conversion
platform_name = "Coding Life"
courses_count = 12
rating = 4.95
is_free = True

# Modern f-strings for seamless string interpolation
summary = f"Platform: {platform_name} | Courses: {courses_count} | Rating: {rating}★"
print(summary)

# Receiving user input (always returns a string)
user_age_str = input("Enter your age: ")
user_age = int(user_age_str) # Type casting from str to int
print(f"Next year you will be {user_age + 1} years old.")

تتميز بايثون بأنها لغة ذات أنواع ديناميكية (Dynamic Typing)، مما يعني أنك لا تحتاج إلى تحديد نوع المتغير مسبقاً، بل يحدده المفسر تلقائياً بناءً على القيمة المعطاة.

أهم أنواع البيانات الأساسية: الأعداد الصحيحة (int)، الأعداد العشرية (float)، النصوص (str)، والقيم المنطقية (True و False بحرف كبير في البداية).

المتغيرات وسلاسل f-strings والتحويل بين الأنواع

# استقبال مدخلات المستخدم عبر دالة input

Lesson 3 — Operators, Comparisons & Logical Expressions

Logic

الدرس 3 — المعاملات البرمجية والعمليات المنطقية

منطق برمجي

Python includes powerful operators designed to read like plain English sentences:

  • Arithmetic: +, -, *, / (float division), // (floor integer division), % (modulo/remainder), ** (exponentiation).
  • Comparison: == (equal), != (not equal), >, <, >=, <=.
  • Logical: and, or, not.
  • Membership: in, not in (Checks presence in a string, list, or dictionary).
Python Operators in Action
score = 85
attendance = 92

# Readable logical expressions
is_eligible = (score >= 80) and (attendance >= 90)
print(f"Eligible for Honors Certificate: {is_eligible}")

# Membership testing
allowed_languages = ["python", "javascript", "html", "css"]
selected = "python"
print(selected in allowed_languages) # True

تتميز معاملات بايثون بأنها تشبه الكلمات الإنجليزية العادية مما يجعل قراءة المنطق بديهية وسهلة:

  • المعاملات الرياضية: +، -، *، /، والأس **، والقسمة الصحيحة //.
  • المعاملات المنطقية: and، or، not.
  • معاملات الانتماء: in للتحقق من وجود عنصر داخل قائمة أو نص.
تطبيق المعاملات المنطقية وفحص الانتماء

attendance = 95

# التحقق المنطقي المزدوج
has_passed = (score >= 75) and (attendance >= 90)

# فحص وجود عنصر في قائمة
skills = ["html", "css", "python"]

Lesson 4 — Control Flow, Conditionals & Indentation Rules

Syntax Rule

الدرس 4 — التحكم في التدفق والشروط وقواعد المسافات البادئة

قاعدة جوهرية

Unlike languages that use curly braces {} to define blocks of code (like JavaScript, C, and Java), Python uses indentation (4 spaces) to determine code structure and scope. Indentation is mandatory and syntax-enforced.

Conditionals with if / elif / else
temperature = 28

if temperature > 30:
    print("Hot day! Stay hydrated.")
elif temperature >= 20:
    print("Pleasant weather for coding outdoors.")
else:
    print("Chilly! Grab a warm coffee.")

# Python Ternary (One-line conditional expression)
status = "Adult" if age >= 18 else "Minor"
Indentation Error: Never mix tabs and spaces in Python files. Configure your editor to convert the Tab key into 4 spaces automatically.

على عكس اللغات التي تستخدم الأقواس المعقوفة {}، تعتمد بايثون على المسافات البادئة (Indentation - 4 مسافات) لتحديد كتل الأكواد ونطاق الجمل الشرطية والدوال. المسافات البادئة في بايثون إجبارية وقاعدة صارمة.

الجمل الشرطية في بايثون
grade = 88

if grade >= 90:
    print("التقدير: ممتاز (A)")
elif grade >= 80:
    print("التقدير: جيد جداً (B)")
elif grade >= 60:
    print("التقدير: مقبول (C)")
else:
    print("يرجى إعادة المحاولة")

# الشرط المختصر في سطر واحد (Ternary Expression)
result = "ناجح" if grade >= 60 else "راسب"

Lesson 5 — Python Collections — Lists, Slicing & Tuples

Data Structures

الدرس 5 — مجموعات بايثون — القوائم (Lists)، الشرائح، والـ Tuples

هياكل البيانات

Lists are mutable (changeable) ordered sequences of items, created with square brackets []. Tuples are immutable (cannot be modified after creation), created with parentheses ().

Powerful Slicing Syntax: list[start:stop:step]

List Operations & List Comprehensions
languages = ["Python", "JavaScript", "HTML", "CSS", "SQL"]

# Slicing
first_two = languages[:2]      # ['Python', 'JavaScript']
reversed_list = languages[::-1] # Reverse list cleanly

# Modifying lists
languages.append("Git")
languages.remove("HTML")

# Modern List Comprehension (Pythonic Transformation)
numbers = [1, 2, 3, 4, 5, 6]
squares_of_evens = [n**2 for n in numbers if n % 2 == 0]
print(squares_of_evens) # [4, 16, 36]

# Immutable Tuple
coordinates = (31.7917, -7.0926) # (Latitude, Longitude)
Pythonic Power: List comprehensions allow you to filter and transform lists in a single readable line, executing faster than manual for-loops.

القوائم (Lists) هي متتاليات مرتبة وقابلة للتعديل تُعرف بأقواس مربعة []. بينما الـ Tuples هي مجموعات ثابتة غير قابلة للتعديل بعد إنشائها وتُكتب بأقواس دائرية ().

تقطيع القوائم والاشتقاق السريع (List Comprehension)
courses = ["HTML", "CSS", "JavaScript", "Python", "SQL"]

# تقطيع القوائم (Slicing)
first_three = courses[:3] # العناصر الثلاثة الأولى
reversed_courses = courses[::-1] # عكس القائمة كاملة

# اشتقاق القوائم السريع (List Comprehension)
numbers = [1, 2, 3, 4, 5, 6]
evens = [x * 2 for x in numbers if x % 2 == 0]
print(evens) # [4, 8, 12]

# زوج إحداثيات ثابت عبر Tuple
coordinates = (33.5731, -7.5898)

Lesson 6 — Dictionaries & Sets — Key-Value Mastery

Hash Maps

الدرس 6 — القواميس (Dictionaries) والمجموعات (Sets)

جداول التجزئة

Dictionaries (dict) store data in key-value pairs with instant O(1) lookup speed. Sets (set) store unordered collections of unique elements, automatically eliminating duplicates.

Working with Dictionaries and Sets
student = {
    "name": "Bilal",
    "track": "Full-Stack Development",
    "completed_lessons": 8,
    "is_certified": False
}

# Accessing values safely using .get() to prevent KeyErrors
track = student.get("track", "Unknown Track")

# Iterating over key-value pairs
for key, value in student.items():
    print(f"{key}: {value}")

# Sets for unique deduplication
raw_tags = ["python", "web", "python", "backend", "web", "ai"]
unique_tags = set(raw_tags)
print(unique_tags) # {'python', 'web', 'backend', 'ai'}
Safe Access: Always use dict.get(key, default) instead of dict[key]. If the key doesn't exist, .get() returns None or your default value instead of crashing your program with a KeyError.

القواميس (Dictionaries) تخزن البيانات على هيئة أزواج (مفتاح وقيمة) بسرعة استرجاع فائقة. أما المجموعات (Sets) فهي لحفظ عناصر فريدة وغير مكررة تلقائياً.

التعامل مع القواميس والمجموعات الفريدة
user = {
    "name": "بلال",
    "role": "مهندس برمجيات",
    "courses_completed": 5
}

# الوصول الآمن عبر get لتفادي انهيار البرنامج
role = user.get("role", "مطور عام")

# التكرار على المفاتيح والقيم
for k, v in user.items():
    print(f"{k} -> {v}")

# إزالة التكرار تلقائياً عبر المجموعات (Sets)
tags = ["python", "ai", "python", "data", "ai"]
clean_tags = set(tags) # {'python', 'ai', 'data'}

Lesson 7 — Loops & Iterations (for, while, range, enumerate)

Iteration

الدرس 7 — حلقات التكرار (for, while, range, enumerate)

تكرار ومعالجة

Python's for loop iterates over items of any iterable (list, string, dictionary, generator). Built-in helper functions like range(), enumerate(), and zip() make looping expressive and bug-free.

Iterating with range, enumerate, and zip
# 1. Loop with range(start, stop, step)
for i in range(1, 6):
    print(f"Step {i}")

# 2. enumerate() provides both index AND value simultaneously
modules = ["HTML5", "CSS3", "JavaScript", "Python"]
for idx, module in enumerate(modules, start=1):
    print(f"{idx}. {module}")

# 3. zip() pairs multiple lists together in parallel
teachers = ["Bilal", "Sarah", "Youssef"]
subjects = ["Web Dev", "Data Science", "DevOps"]
for teacher, subject in zip(teachers, subjects):
    print(f"{teacher} teaches {subject}")

تتميز حلقة for في بايثون بالمرونة العالية عبر دوال مساعدة مدمجة مثل range() لتوليد الأرقام، و enumerate() للحصول على الفهرس والقيمة معاً، و zip() للدمج بين قائمتين متوازيتين.

أمثلة متقدمة لحلقات التكرار
# التكرار مع الفهرس باستخدام enumerate
lessons = ["المتغيرات", "الشروط", "الدوال", "الكائنات"]
for index, title in enumerate(lessons, start=1):
    print(f"الدرس {index}: {title}")

# الدمج المتوازي بين قائمتين بـ zip
students = ["علي", "مريم", "حمزة"]
scores = [95, 98, 91]
for s, sc in zip(students, scores):
    print(f"الطالب {s} حصل على {sc}%")

Lesson 8 — Functions, *args, **kwargs & Lambda Expressions

Modular Code

الدرس 8 — الدوال، المعاملات المرنة (*args, **kwargs)، ودوال Lambda

كود تركيبي

Functions encapsulate logic into reusable subroutines. Python supports default arguments, variable positional arguments (*args), and variable keyword arguments (**kwargs).

Modern Python Functions & Lambda
# Standard function with docstring and default parameter
def calculate_price(base_price: float, tax_rate: float = 0.20) -> float:
    # Calculates final price including sales tax
    return base_price + (base_price * tax_rate)

# Flexible function accepting arbitrary positional & keyword arguments
def log_event(event_name, *tags, **metadata):
    print(f"Event: {event_name}")
    print(f"Tags: {tags}")
    print(f"Metadata: {metadata}")

log_event("UserSignup", "web", "organic", user_id=1024, country="MA")

# Anonymous one-line lambda function
double = lambda x: x * 2
print(double(7)) # 14

الدوال تجمع الأوامر البرمجية لسهولة إعادة استخدامها وصيانتها. تدعم بايثون قيماً افتراضية للمعاملات وقبول عدد غير محدد من المتغيرات عبر *args و **kwargs.

دوال بايثون والمعاملات المرنة
# دالة حسابية مع قيمة افتراضية للضريبة
def calculate_total(price, tax=0.20):
    return price + (price * tax)

# دالة مرنة تقبل عدداً غير محدد من المعاملات
def register_user(username, *roles, **details):
    print(f"المستخدم: {username}")
    print(f"الأدوار: {roles}")
    print(f"البيانات الإضافية: {details}")

register_user("bilal", "admin", "author", country="المغرب", level=5)

Lesson 9 — Object-Oriented Programming (OOP) in Python

OOP

الدرس 9 — البرمجة كائنية التوجه (OOP) في بايثون

البرمجة الكائنية

Object-Oriented Programming (OOP) structures software design around data, or objects, rather than functions and logic. It relies on four pillars: Encapsulation, Abstraction, Inheritance, and Polymorphism.

Classes, Constructor, and Inheritance
class Course:
    def __init__(self, title: str, instructor: str, hours: int):
        self.title = title
        self.instructor = instructor
        self.hours = hours
        self.enrolled_students = []

    def enroll(self, student_name: str):
        self.enrolled_students.append(student_name)
        print(f"{student_name} successfully enrolled in {self.title}.")

    def summary(self):
        return f"Course: {self.title} ({self.hours}h) by {self.instructor}"

# Child Class inheriting from Course
class InteractiveCourse(Course):
    def __init__(self, title, instructor, hours, has_quiz=True):
        super().__init__(title, instructor, hours)
        self.has_quiz = has_quiz

py_course = InteractiveCourse("Python 3 Masterclass", "Bilal", 6)
py_course.enroll("Karim")
print(py_course.summary())

البرمجة كائنية التوجه (OOP) هي نموذج لتنظيم البرمجيات حول كائنات تحتوي على بيانات وخصائص ووظائف سلوكية خاصة بها، مما يسهل إدارة المشاريع الكبيرة وتطويرها.

الفئات (Classes) والتوريث في بايثون
class Course:
    def __init__(self, title, instructor, hours):
        self.title = title
        self.instructor = instructor
        self.hours = hours

    def get_info(self):
        return f"الدورة: {self.title} | المدرب: {self.instructor}"

# فئة فرعية ترث من الفئة الرئيسية
class ProCourse(Course):
    def __init__(self, title, instructor, hours, certificate=True):
        super().__init__(title, instructor, hours)
        self.certificate = certificate

course1 = ProCourse("بايثون الاحترافية", "بلال", 6)
print(course1.get_info())

Lesson 10 — File Handling, Exception Handling & Virtual Environments

Production Ready

الدرس 10 — معالجة الملفات، إدارة الأخطاء (try/except)، والبيئات الافتراضية

جاهزية الإنتاج

Real-world software interacts with the filesystem, catches unexpected errors gracefully, and manages external dependencies safely via virtual environments.

Safe File Handling and Robust Error Handling
# 1. File Handling with Context Manager ('with')
# 'with' guarantees the file closes automatically even if errors happen
with open("students.txt", "w", encoding="utf-8") as f:
    f.write("Bilal,Morocco,Advanced\n")
    f.write("Sarah,Egypt,Intermediate\n")

# Reading the file back
with open("students.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

# 2. Robust Exception Handling (try / except / finally)
try:
    number = int(input("Enter an integer: "))
    result = 100 / number
    print(f"Result: {result}")
except ValueError:
    print("Invalid input! Please enter digits only.")
except ZeroDivisionError:
    print("Cannot divide by zero!")
finally:
    print("Execution complete.")
