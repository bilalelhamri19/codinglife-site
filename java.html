1. What is Java & History

1. ما هو Java وتاريخه

1. Qu'est-ce que Java ?

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. Released by Sun Microsystems in 1995 (now owned by Oracle), its defining motto is: "Write Once, Run Anywhere" (WORA).

This cross-platform capability is achieved via bytecode, which runs on the Java Virtual Machine (JVM) regardless of the underlying computer architecture (Windows, macOS, Linux, Android).

جافا (Java) هي لغة برمجة عالية المستوى، كائنية التوجه (OOP)، صممت بهدف تقليل الاعتماد على البنية التحتية للأجهزة إلى أدنى حد. أطلقتها شركة Sun Microsystems سنة 1995، وشعارها الشهير: "اكتب مرة واحدة، ونفّذ في أي مكان" (Write Once, Run Anywhere).

تتحقق هذه المرونة عبر ترجمة الكود المصدري إلى Bytecode يشتغل فوق آلة جافا الافتراضية (JVM) بسلاسة على ويندوز، ماك، لينكس وأندرويد.

Java est un langage de programmation orienté objet de haut niveau. Créé par Sun Microsystems en 1995 (aujourd'hui Oracle), son principe fondateur est : "Write Once, Run Anywhere" (WORA).

Le code Java est compilé en bytecode exécuté par la machine virtuelle Java (JVM), rendant vos applications indépendantes du système d'exploitation.

Getting Started

2. Installing JDK 21 & First Program

2. التثبيت وأول برنامج في جافا

2. Installation & Premier Programme

To start coding in Java, you need the Java Development Kit (JDK). We recommend OpenJDK 21 (LTS). Every Java application begins with a class containing a main method.

للبدء في كتابة كود جافا، تحتاج لتثبيت حزمة JDK (Java Development Kit). نوصي بإصدار OpenJDK 21 (LTS). يبدأ أي برنامج جافا داخل صنف (class) يحتوي دالة الدخول main.

Pour développer, installez le JDK (Java Development Kit) version 21 (LTS). Tout programme Java démarre dans une classe contenant la méthode main.

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Coding Life World!");
    }
}
Data Types

3. Variables and Static Typing

3. المتغيرات وأنواع البيانات

3. Variables et Types de Données

Java is strictly and statically typed. You must declare the type of each variable before using it. Java provides primitive types (int, double, boolean, char) and reference types like String.

جافا لغة ذات كتابة نوعية صارمة (Strictly Typed). يجب تحديد نوع كل متغير بوضوح، مثل الأنواع الأساسية (int, double, boolean) أو المرجعية مثل String.

Java est un langage typé statiquement. Les types primitifs incluent int, double, boolean, et les types objets comme String.

int age = 20;
double price = 19.99;
String channel = "Coding Life";
boolean isStudent = true;
Conditionals

4. Operators & Control Flow

4. العمليات والشروط (Conditions)

4. Opérateurs et Conditions

Make decisions in your code using conditional structures: if, else if, else, and modern pattern-matching switch expressions.

اتخاذ القرارات البرمجية عبر أدوات الشرط if, else if, else ومفتاح الاختيار الحديث switch.

Contrôlez le flux d'exécution grâce aux structures conditionnelles if / else et aux blocs switch.

int score = 85;
if (score >= 90) {
    System.out.println("Grade: A");
} else if (score >= 80) {
    System.out.println("Grade: B");
} else {
    System.out.println("Keep pushing!");
}

5. Loops and Arrays

5. الحلقات التكرارية والمصفوفات

5. Boucles et Tableaux

Arrays hold fixed-size elements of the same data type. Traverse them cleanly using traditional for loops or enhanced for-each loops.

تسمح المصفوفات بتخزين مجموعة عناصر من نفس النوع بحجم محدد مسبقاً. يمكن المرور عليها باستخدام حلقة for-each الأنيقة.

Les tableaux stockent une taille fixe d'éléments du même type. Parcourez-les facilement avec la boucle for-each.

String[] languages = {"Java", "Python", "TypeScript"};

for (String lang : languages) {
    System.out.println("Mastering: " + lang);
}
Functions

6. Methods (Functions & Parameters)

6. الدوال والوظائف (Methods)

6. Méthodes (Fonctions)

Methods promote code reusability and clean architecture. A method defines an access modifier, return type, name, and input parameters.

تساعد الدوال (Methods) في إعادة استخدام الكود وتنظيمه. تحدد الدالة نوع الإرجاع، الاسم، والمعاملات المستقبلة.

Les méthodes permettent de découper et réutiliser votre code. Définissez le type de retour, le nom et les paramètres.

public static int calculateSum(int a, int b) {
    return a + b;
}
Core Pillar

7. OOP — The 4 Pillars of Java

7. البرمجة كائنية التوجه (POO)

7. Les 4 Piliers de la POO

Object-Oriented Programming (OOP) is the core foundation of Java software engineering:

  • Encapsulation: Private variables with public getter/setter methods.
  • Inheritance: Reusing code using the extends keyword.
  • Polymorphism: Overriding methods (@Override) to behave differently.
  • Abstraction: Defining contracts using interface and abstract class.

البرمجة كائنية التوجه (OOP) هي العمود الفقري لتطوير البرمجيات في جافا، وترتكز على 4 مبادئ أساسية:

  • التغليف (Encapsulation): حماية البيانات بالمتغيرات الخاصة (private) ودوال الوصول.
  • الوراثة (Inheritance): وراثة الخصائص باستخدام extends.
  • تعدد الأشكال (Polymorphism): إعادة تعريف الدوال لتتصرف بمرونة (@Override).
  • التجريد (Abstraction): بناء هياكل ومخططات عبر interface و abstract.

La Programmation Orientée Objet (POO) est au cœur de Java : Encapsulation, Héritage, Polymorphisme et Abstraction.

class Developer {
    private String name;
    
    public Developer(String name) { this.name = name; }
    public void code() { System.out.println(name + " is building great software!"); }
}
Collections

8. Collections (ArrayList & HashMap)

8. هياكل البيانات والمجموعات (Collections)

8. Collections (ArrayList & HashMap)

Handle dynamic datasets effortlessly. ArrayList provides resizable arrays, while HashMap stores lightning-fast key-value mappings.

التعامل مع قوائم البيانات الديناميكية باستخدام ArrayList، وقواميس المفتاح-القيمة فائقة السرعة مع HashMap.

Gérez des listes dynamiques avec ArrayList et des paires clé-valeur ultra-rapides avec HashMap.

import java.util.*;

List skills = new ArrayList<>();
skills.add("Java Core");
skills.add("Spring Boot");

Map rankings = new HashMap<>();
rankings.put("Coding Life", 1);
Reliability

9. Exception Handling & Resilience

9. معالجة الاستثناءات والأخطاء (Exceptions)

9. Gestion des Exceptions

Ensure your production systems never crash. Catch unexpected runtime issues with structured try-catch-finally blocks and custom business exceptions.

حماية البرنامج من الانهيار المفاجئ عبر التقاط الأخطاء ومعالجتها باحترافية عبر try و catch و finally.

Évitez les plantages en production grâce aux blocs de capture try, catch et finally.

try {
    int result = 100 / 0;
} catch (ArithmeticException e) {
    System.err.println("Safely handled division error: " + e.getMessage());
} finally {
    System.out.println("Execution completed safely.");
}
Modern Standards

10. Modern Java (Lambdas & Stream API)

10. جافا الحديثة (Lambda & Stream API)

10. Java Moderne (Lambda & Streams)

Modern Java embraces functional programming. Use concise lambda expressions and the declarative Stream API to filter, transform, and aggregate collections cleanly.

تدعم جافا الحديثة البرمجة الوظيفية (Functional Programming). تتيح تعبيرات Lambda وواجهة Stream API تصفية وتحويل البيانات بسطور برمجية مقتضبة وأنيقة.

Écrivez du code concis et expressif grâce aux expressions Lambda et à l'API Stream de Java moderne.

List languages = List.of("Java", "JavaScript", "Python", "Go");

languages.stream()
         .filter(name -> name.startsWith("J"))
         .map(String::toUpperCase)
         .forEach(System.out::println);

Where to go next after mastering the fundamentals? Here is the industry-standard progression path:

La trajectoire idéale : Java Core -> Maven/Gradle -> Spring Boot 3 -> Microservices & Docker.
