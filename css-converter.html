Unit Theory: Which one to use?

Choosing the right unit is the difference between a broken layout and a perfectly responsive masterpiece.

1. Absolute Units: px

Pixels are absolute and don't scale. Great for borders or fixed-size icons, but dangerous for typography because they ignore user accessibility settings.

2. Root Relative: rem

Relative to the root <html> font size. This is the industry standard for accessible typography. If the user changes their browser font size, your site scales beautifully.

3. Parent Relative: em

Relative to the font size of the element itself. Perfect for components that need to maintain their proportions regardless of where they are placed.

4. Viewport Units: vw / vh

Relative to the browser window size. Use vh for full-screen hero sections and vw for typography that needs to grow with the screen width.
