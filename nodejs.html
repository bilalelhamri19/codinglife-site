معمارية Node.js القابلة للتوسع

الدليل النهائي المكون من 200 قسم لهندسة الأنظمة الخلفية عالية الأداء باستخدام جافا سكريبت ومحرك V8.

1. The Event-Driven Non-Blocking Model

Node.js revolutionized server-side development by enabling JavaScript to run on the server using an event-driven, non-blocking I/O model. In this section, we explore the internal workings of Libuv, the Event Loop phases (Timers, Poll, Check), and how Node handles thousands of concurrent connections on a single thread. We will also perform our first professional installation using NVM.

1. النموذج المعتمد على الأحداث وغير الحاصر

أحدث Node.js ثورة في تطوير الأنظمة الخلفية من خلال تمكين جافا سكريبت من العمل على السيرفر باستخدام نموذج I/O معتمد على الأحداث وغير حاصر. في هذا القسم، نستكشف العمليات الداخلية لـ Libuv، مراحل حلقة الأحداث (Event Loop)، وكيف يعالج Node آلاف الاتصالات المتزامنة على خيط واحد. سنقوم أيضًا بأول تثبيت احترافي باستخدام NVM.
