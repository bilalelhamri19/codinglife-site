Chapter 1: The Semantic Revolution

In the professional world, <div> soup is a sign of an amateur. Semantic HTML is about using tags that describe their content, not their appearance.

Bad Practice <div class="header">...</div>
Pro Practice <header>...</header>

Why it matters:

  • SEO: Google gives higher weight to content inside semantic tags like <h1>, <article>, and <main>.
  • Accessibility: Screen readers use these tags to help blind users navigate the page.

Chapter 2: A11y & ARIA Roles

Accessibility (A11y) is not a feature; it's a requirement. If your site isn't accessible, you're losing 15% of your potential audience.

<!-- Accessible Icon Button -->
<button aria-label="Close Menu" title="Close">
    <i class="fa-solid fa-xmark" aria-hidden="true"></i>
</button>

<!-- Descriptive Links -->
<a href="/docs" aria-describedby="doc-info">Read Docs</a>
<p id="doc-info" hidden>Opens a 2MB PDF file in a new tab.</p>

Chapter 3: HTML5 Power APIs

HTML5 is more than just markup. It provides powerful APIs that previously required complex plugins.

  • Canvas API: For 2D and 3D graphics and games.
  • Drag & Drop: Native support for dragging elements.
  • Web Storage: localStorage and sessionStorage for saving data in the browser.

Chapter 4: Data Mastery (Tables & Lists)

Tables should be used for tabular data, never for layout. A pro table uses thead, tbody, and tfoot.

<table>
  <caption>Quarterly Sales Report</caption>
  <thead>
    <tr>
      <th scope="col">Product</th>
      <th scope="col">Revenue</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Premium Path</th>
      <td>$12,400</td>
    </tr>
  </tbody>
</table>

Interactive Challenge

Try to identify the semantic error in this snippet:

<div class="nav">
  <div class="item">Home</div>
  <div class="item">Blog</div>
</div>
Reveal Pro Solution

A navigation should use the <nav> tag and an unordered list (<ul>) for the items. This is standard for screen readers and search crawlers.

<nav>
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/blog">Blog</a></li>
  </ul>
</nav>
