Lesson 1 — What is HTML5 & How the Web Works

Beginner

الدرس 1 — ما هو HTML5 وكيف يعمل الويب

مبتدئ

HTML stands for HyperText Markup Language. It is the standard language used to create and structure content on the web. Every website you visit — from Google to YouTube — is built upon an HTML foundation.

HTML is NOT a programming language. It does not have logic, conditions, or loops. Instead, it is a markup language, meaning you use special tags to annotate text and tell the browser how to display it. The browser (Chrome, Firefox, Safari) reads these tags and renders the visual page you see.

How does the web work? When you type a URL in your browser, your computer sends a request to a server. That server responds by sending back an HTML file. Your browser then parses the HTML and displays it as the page you see. CSS adds styling (colors, fonts, layout) and JavaScript adds interactivity (buttons, animations, dynamic content).

HTML5 is the latest version of HTML, officially standardized in 2014. It brought major improvements: native audio/video support, semantic elements (<article>, <section>), canvas for graphics, local storage, and much more.

Key insight: HTML is the skeleton of a web page. CSS is the skin and clothes. JavaScript is the muscles and brain. You need all three to build a complete website.

HTML هي اختصار لـ HyperText Markup Language، أي لغة ترميز النص التشعبي. هي اللغة القياسية المستخدمة لإنشاء وهيكلة المحتوى على الويب. كل موقع تزوره — من Google إلى YouTube — مبني على أساس HTML.

HTML ليست لغة برمجة. ليس لديها منطق أو شروط أو حلقات تكرار. بدلاً من ذلك، هي لغة ترميز، ما يعني أنك تستخدم وسوماً خاصة للتعليق على النص وإخبار المتصفح بكيفية عرضه. يقرأ المتصفح (Chrome أو Firefox أو Safari) هذه الوسوم ويعرض الصفحة المرئية.

كيف يعمل الويب؟ عندما تكتب URL في متصفحك، يرسل جهاز الكمبيوتر الخاص بك طلباً إلى خادم. يستجيب ذلك الخادم بإرسال ملف HTML. يقوم المتصفح بعد ذلك بتحليل HTML وعرضها كالصفحة التي تراها. تضيف CSS التنسيق (الألوان والخطوط والتخطيط) ويضيف JavaScript التفاعلية.

HTML5 هو أحدث إصدار من HTML، تم توحيده رسمياً في 2014. جلب تحسينات كبيرة: دعم الصوت والفيديو الأصلي، العناصر الدلالية، canvas للرسومات، التخزين المحلي، والكثير.

نقطة مهمة: HTML هي هيكل صفحة الويب، CSS هي الجلد والملابس، وJavaScript هي العضلات والعقل. تحتاج إلى الثلاثة لبناء موقع كامل.

Lesson 2 — Document Structure & Boilerplate

Essential

الدرس 2 — هيكل المستند والكود الأساسي

أساسي

Every HTML document follows a specific structure. This structure is called the HTML boilerplate — the minimum code every web page needs to be valid and correctly interpreted by browsers.

Standard HTML5 Boilerplate
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page Title</title>
    <meta name="description" content="Page description for SEO">
    <link rel="stylesheet" href="styles.css">
  </head>
  <body>
    <h1>Hello, World!</h1>
    <script src="script.js"></script>
  </body>
</html>

Let's break down each part:

  • <!DOCTYPE html> — Tells the browser this is an HTML5 document. Always the very first line.
  • <html lang="en"> — The root element. The lang attribute helps screen readers and search engines understand the language.
  • <head> — Contains metadata (information about the page) that is NOT displayed on screen: title, charset, styles, meta tags.
  • charset="UTF-8" — Sets character encoding. UTF-8 supports all languages including Arabic, Chinese, and emojis.
  • viewport meta tag — Critical for mobile responsiveness. Without it, mobile browsers zoom out and the page looks tiny.
  • <title> — Shown in the browser tab and search engine results. Crucial for SEO.
  • <body> — Everything inside here is displayed on the page: text, images, buttons, etc.
Always place <script> tags at the bottom of the body, just before </body>. This ensures the HTML loads and displays before JavaScript runs, improving page load speed.
Common Mistake: Forgetting the lang attribute on the <html> tag. This hurts SEO and accessibility scores significantly.

كل مستند HTML يتبع بنية محددة. تُسمى هذه البنية HTML Boilerplate — الحد الأدنى من الكود الذي يحتاجه كل صفحة ويب لتكون صالحة ويتم تفسيرها بشكل صحيح من قبل المتصفحات.

النموذج الأساسي لـ HTML5
<!DOCTYPE html>
<html lang="ar">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>عنوان صفحتي</title>
    <meta name="description" content="وصف الصفحة للسيو">
    <link rel="stylesheet" href="styles.css">
  </head>
  <body>
    <h1>مرحباً بالعالم!</h1>
    <script src="script.js"></script>
  </body>
</html>

دعنا نحلل كل جزء:

  • <!DOCTYPE html> — يخبر المتصفح أن هذا مستند HTML5. دائماً السطر الأول.
  • <html lang="ar"> — العنصر الجذر. سمة lang تساعد برامج قراءة الشاشة ومحركات البحث على فهم اللغة.
  • <head> — يحتوي على البيانات الوصفية التي لا تظهر على الشاشة: العنوان والترميز والأنماط.
  • charset="UTF-8" — يضبط ترميز المحارف. UTF-8 يدعم جميع اللغات بما فيها العربية والصينية والرموز التعبيرية.
  • وسم viewport — حيوي للاستجابة على الهاتف. بدونه، تبدو الصفحة مصغرة جداً على الهواتف.
  • <title> — يظهر في علامة تبويب المتصفح ونتائج محرك البحث. حاسم للسيو.
  • <body> — كل شيء بداخله يظهر على الصفحة: نصوص وصور وأزرار وغيرها.
ضع دائماً وسوم <script> في نهاية body، قبل </body> مباشرة. يضمن ذلك تحميل HTML وعرضها قبل تشغيل JavaScript، مما يحسن سرعة التحميل.
خطأ شائع: نسيان سمة lang على وسم <html>. يضر هذا بدرجات السيو وسهولة الوصول بشكل كبير.

Lesson 3 — Headings, Paragraphs & Text Formatting

SEO Critical

الدرس 3 — العناوين والفقرات وتنسيق النص

حيوي للسيو

HTML provides six levels of headings (h1 to h6) and the basic paragraph tag <p>. These are not just visual elements — they carry deep semantic meaning for search engines and screen readers.

Headings & Paragraphs
<h1>Main Page Title (Use ONLY ONCE per page)</h1>
<h2>Major Section</h2>
<h3>Subsection</h3>
<h4>Minor Heading</h4>
<p>This is a paragraph of text. It can contain <strong>bold text</strong>,
<em>italic text</em>, and <mark>highlighted text</mark>.</p>

<!-- Line break (avoid overusing) -->
<br>

<!-- Horizontal rule -->
<hr>

Text formatting tags you must know:

  • <strong> — Bold AND semantically important (better than <b> for SEO)
  • <em> — Italic AND semantically emphasized (better than <i>)
  • <mark> — Highlighted/marked text
  • <code> — Inline code snippet
  • <blockquote> — A quote from another source
  • <abbr title="..."> — Abbreviation with tooltip
  • <del> / <ins> — Deleted / Inserted text
  • <sup> / <sub> — Superscript / Subscript
SEO Rule: Every page must have exactly ONE <h1> tag — your main title. Use <h2> for sections, <h3> for subsections. Never skip heading levels (don't jump from h1 to h4). Google uses this hierarchy to understand your page structure.

يوفر HTML ستة مستويات من العناوين (من h1 إلى h6) ووسم الفقرة الأساسي <p>. هذه ليست مجرد عناصر مرئية — بل تحمل معنى دلالياً عميقاً لمحركات البحث وبرامج قراءة الشاشة.

العناوين والفقرات
<h1>عنوان الصفحة الرئيسي (استخدم مرة واحدة فقط في الصفحة)</h1>
<h2>قسم رئيسي</h2>
<h3>قسم فرعي</h3>
<p>هذه فقرة نصية. يمكنها احتواء <strong>نص عريض</strong>
و<em>نص مائل</em> و<mark>نص مظلل</mark>.</p>

وسوم تنسيق النص التي يجب معرفتها:

  • <strong> — نص عريض وذو أهمية دلالية (أفضل من <b> للسيو)
  • <em> — نص مائل ومؤكد دلالياً (أفضل من <i>)
  • <mark> — نص مظلل أو مميز
  • <code> — مقتطف كود مضمّن
  • <blockquote> — اقتباس من مصدر آخر
  • <del> / <ins> — نص محذوف / مُدرج
  • <sup> / <sub> — نص مرتفع / منخفض
قاعدة السيو: يجب أن تحتوي كل صفحة على وسم <h1> واحد فقط — عنوانك الرئيسي. استخدم <h2> للأقسام و<h3> للأقسام الفرعية. لا تتخطى مستويات العناوين أبداً. تستخدم Google هذا التسلسل الهرمي لفهم بنية صفحتك.

Lesson 4 — Links, Anchors & Navigation

Essential

الدرس 4 — الروابط والمراسي والتنقل

أساسي

The <a> (anchor) tag is one of the most powerful elements in HTML. It connects pages together, making the web truly a network of documents. Without links, there would be no web.

Link Types & Attributes
<!-- External link (opens in new tab) -->
<a href="https://google.com" target="_blank" rel="noopener noreferrer">Visit Google</a>

<!-- Internal link (same website) -->
<a href="about.html">About Us</a>
<a href="/courses/python.html">Python Course</a>

<!-- Anchor link (jump to section on same page) -->
<a href="#lesson-5">Go to Lesson 5</a>
<div id="lesson-5">...</div>

<!-- Email and phone links -->
<a href="mailto:hello@example.com">Send Email</a>
<a href="tel:+212600000000">Call Us</a>

<!-- Download link -->
<a href="resume.pdf" download>Download Resume</a>
  • href — The URL or destination. Required.
  • target="_blank" — Opens link in a new browser tab.
  • rel="noopener noreferrer" — Security best practice when using target="_blank". Prevents the linked page from accessing your page's window object.
  • download — Forces the browser to download the file instead of opening it.
Security Warning: Always add rel="noopener noreferrer" when using target="_blank". Without it, the external page can redirect your page — a security vulnerability known as "tabnapping".

وسم <a> (المرساة) هو أحد أقوى العناصر في HTML. يربط الصفحات ببعضها، مما يجعل الويب شبكة حقيقية من المستندات. بدون الروابط، لن يكون هناك ويب.

أنواع الروابط والسمات
<!-- رابط خارجي (يفتح في تبويب جديد) -->
<a href="https://google.com" target="_blank" rel="noopener noreferrer">زيارة جوجل</a>

<!-- رابط داخلي (نفس الموقع) -->
<a href="about.html">من نحن</a>

<!-- رابط مرساة (القفز إلى قسم في نفس الصفحة) -->
<a href="#lesson-5">الذهاب للدرس 5</a>
<div id="lesson-5">...</div>

<!-- روابط البريد الإلكتروني والهاتف -->
<a href="mailto:hello@example.com">إرسال بريد</a>
<a href="tel:+212600000000">اتصل بنا</a>

<!-- رابط التنزيل -->
<a href="resume.pdf" download>تنزيل السيرة الذاتية</a>
تحذير أمني: أضف دائماً rel="noopener noreferrer" عند استخدام target="_blank". بدونها، يمكن للصفحة الخارجية إعادة توجيه صفحتك — وهي ثغرة أمنية تُعرف بـ "tabnapping".

Lesson 5 — Images, Audio & Video

Beginner

الدرس 5 — الصور والصوت والفيديو

مبتدئ

HTML5 introduced native support for images, audio, and video — no plugins or Flash required. The <img>, <audio>, and <video> tags allow you to embed rich media directly in your pages.

Images, Audio & Video
<!-- Image with all best-practice attributes -->
<img
  src="assets/images/photo.jpg"
  alt="A developer typing code on a laptop"
  width="800"
  height="450"
  loading="lazy">

<!-- Responsive image with multiple sources -->
<picture>
  <source srcset="photo.webp" type="image/webp">
  <img src="assets/images/photo.jpg" alt="Developer at work">
</picture>

<!-- Audio player -->
<audio controls>
  <source src="podcast.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

<!-- Video player -->
<video controls width="640" poster="thumbnail.jpg">
  <source src="tutorial.mp4" type="video/mp4">
  Your browser does not support video.
</video>
  • alt — Alternative text. Shown when image fails to load. Critical for SEO and accessibility. Describe the image clearly.
  • loading="lazy" — Native lazy loading. Images only load when they enter the viewport. Dramatically improves page speed.
  • width & height — Always specify these to prevent Cumulative Layout Shift (CLS), which hurts your Google PageSpeed score.
  • <picture> — Allows providing multiple image formats. WebP is smaller and faster than JPEG/PNG — always offer it as the first option.
Performance tip: Use the WebP format for images — it's 25-35% smaller than JPEG at the same quality. Always add loading="lazy" to images below the fold. These two changes alone can cut your page load time in half.

قدم HTML5 دعماً أصلياً للصور والصوت والفيديو — لا حاجة لإضافات أو Flash. تسمح وسوم <img> و<audio> و<video> بتضمين الوسائط الغنية مباشرة في صفحاتك.

الصور والصوت والفيديو
<!-- صورة بجميع سمات أفضل الممارسات -->
<img
  src="assets/images/photo.jpg"
  alt="مطور يكتب كوداً على حاسوب محمول"
  width="800"
  height="450"
  loading="lazy">

<!-- صورة متجاوبة مع مصادر متعددة -->
<picture>
  <source srcset="photo.webp" type="image/webp">
  <img src="assets/images/photo.jpg" alt="مطور في العمل">
</picture>

<!-- مشغل الصوت -->
<audio controls>
  <source src="podcast.mp3" type="audio/mpeg">
  متصفحك لا يدعم الصوت.
</audio>
  • alt — النص البديل. يظهر عند فشل تحميل الصورة. حيوي للسيو وسهولة الوصول.
  • loading="lazy" — التحميل الكسول الأصلي. تُحمَّل الصور فقط عند دخولها نطاق الرؤية. يحسن سرعة الصفحة بشكل كبير.
  • width وheight — حددهما دائماً لمنع الانزياح التراكمي للتخطيط (CLS).
نصيحة للأداء: استخدم صيغة WebP للصور — أصغر بنسبة 25-35% من JPEG بنفس الجودة. أضف دائماً loading="lazy" للصور أسفل الطية. هذان التغييران وحدهما يمكنهما تقليص وقت تحميل الصفحة إلى النصف.

Lesson 6 — Lists: Ordered, Unordered & Description

Beginner

الدرس 6 — القوائم: مرتبة وغير مرتبة وتعريفية

مبتدئ

HTML offers three types of lists, each serving a different purpose. Knowing when to use each is important for both semantics and SEO.

<!-- Unordered list (bullets) - use for items without ranking -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<!-- Ordered list (numbers) - use for steps or ranked items -->
<ol>
  <li>Learn HTML first</li>
  <li>Then learn CSS</li>
  <li>Finally, learn JavaScript</li>
</ol>

<!-- Description list - use for glossaries or key-value pairs -->
<dl>
  <dt>HTML</dt>
  <dd>The structure of web pages</dd>
  <dt>CSS</dt>
  <dd>The styling of web pages</dd>
</dl>

<!-- Nested list -->
<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
Use <ul> for navigation menus — it is the semantic standard. Search engines and screen readers expect navigation to be a list. Never use divs or spans for navigation items.

يقدم HTML ثلاثة أنواع من القوائم، كل منها يخدم غرضاً مختلفاً. معرفة متى تستخدم كلاً منها مهمة للدلالة وللسيو.

<!-- قائمة غير مرتبة (نقاط) - للعناصر غير المرتبة -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<!-- قائمة مرتبة (أرقام) - للخطوات أو العناصر المرتبة -->
<ol>
  <li>تعلم HTML أولاً</li>
  <li>ثم تعلم CSS</li>
  <li>أخيراً تعلم JavaScript</li>
</ol>

<!-- قائمة وصفية - للمصطلحات أو أزواج المفتاح-القيمة -->
<dl>
  <dt>HTML</dt>
  <dd>هيكل صفحات الويب</dd>
  <dt>CSS</dt>
  <dd>تنسيق صفحات الويب</dd>
</dl>
استخدم <ul> لقوائم التنقل — إنه المعيار الدلالي. تتوقع محركات البحث وبرامج قراءة الشاشة أن يكون التنقل قائمة. لا تستخدم divs أو spans لعناصر التنقل أبداً.

Lesson 7 — Tables: Structure & Best Practices

Intermediate

الدرس 7 — الجداول: الهيكل وأفضل الممارسات

متوسط

HTML tables are used to display tabular data — data that naturally belongs in rows and columns, like spreadsheets, comparison charts, or schedules. They should never be used for page layout (that's CSS's job).

<table>
  <caption>Programming Language Popularity 2026</caption>
  <thead>
    <tr>
      <th scope="col">Language</th>
      <th scope="col">Usage</th>
      <th scope="col">Difficulty</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>JavaScript</td>
      <td>Frontend & Backend</td>
      <td>Medium</td>
    </tr>
    <tr>
      <td>Python</td>
      <td>AI, Data, Backend</td>
      <td>Easy</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="3">Source: Stack Overflow Survey 2026</td>
    </tr>
  </tfoot>
</table>
  • <caption> — A title for the table. Good for accessibility and SEO.
  • <thead>, <tbody>, <tfoot> — Semantic grouping of rows.
  • <th> — Table header cell (bold by default). Use scope="col" or scope="row".
  • colspan / rowspan — Merge cells horizontally or vertically.
Common Mistake: Using tables for page layout. This was common in the 1990s but is now considered very bad practice. Always use CSS Flexbox or Grid for layouts.

تُستخدم جداول HTML لعرض البيانات الجدولية — البيانات التي تنتمي بشكل طبيعي في صفوف وأعمدة، مثل جداول البيانات ومخططات المقارنة والجداول الزمنية. يجب أن تُستخدم أبداً لتخطيط الصفحات (ذلك عمل CSS).

<table>
  <caption>شعبية لغات البرمجة 2026</caption>
  <thead>
    <tr>
      <th scope="col">اللغة</th>
      <th scope="col">الاستخدام</th>
      <th scope="col">الصعوبة</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>JavaScript</td>
      <td>Frontend وBackend</td>
      <td>متوسط</td>
    </tr>
    <tr>
      <td>Python</td>
      <td>ذكاء اصطناعي وبيانات</td>
      <td>سهل</td>
    </tr>
  </tbody>
</table>
خطأ شائع: استخدام الجداول لتخطيط الصفحات. كان هذا شائعاً في التسعينيات ولكنه الآن ممارسة سيئة جداً. استخدم دائماً CSS Flexbox أو Grid للتخطيطات.

Lesson 8 — Forms: Input, Validation & Accessibility

Essential

الدرس 8 — النماذج: المدخلات والتحقق وسهولة الوصول

أساسي

Forms are how websites collect user input — login screens, contact forms, search bars, checkouts. HTML5 brought powerful native validation and many new input types that work without JavaScript.

<form action="/submit" method="POST">
  <!-- Text Input -->
  <label for="name">Full Name</label>
  <input type="text" id="name" name="name" placeholder="John Doe" required minlength="2">

  <!-- Email with built-in validation -->
  <label for="email">Email Address</label>
  <input type="email" id="email" name="email" required>

  <!-- Password -->
  <input type="password" id="pass" name="pass" minlength="8" required>

  <!-- Number input -->
  <input type="number" min="1" max="100" step="1">

  <!-- Date picker -->
  <input type="date">

  <!-- Dropdown select -->
  <select name="level">
    <option value="">Select Level</option>
    <option value="beginner">Beginner</option>
    <option value="pro">Professional</option>
  </select>

  <!-- Textarea -->
  <textarea name="message" rows="5" placeholder="Your message..."></textarea>

  <!-- Checkbox & Radio -->
  <input type="checkbox" id="agree" name="agree" required>
  <label for="agree">I agree to the Terms</label>

  <button type="submit">Send Message</button>
</form>
  • <label for="..."> — Always connect labels to inputs with for matching the input id. Required for accessibility. Clicking the label focuses the input.
  • required — Browser-native validation. Shows an error if user tries to submit without filling the field.
  • minlength / maxlength — Character count validation.
  • type="email" — Auto-validates email format. Shows a custom keyboard on mobile.
Mobile tip: Use the right type attribute: type="tel" shows a number pad on mobile, type="email" shows the @ keyboard, type="url" shows a URL keyboard. This small detail greatly improves mobile user experience.

النماذج هي الطريقة التي تجمع بها المواقع مدخلات المستخدمين — شاشات تسجيل الدخول ونماذج التواصل وأشرطة البحث. جلب HTML5 تحققاً أصلياً قوياً وأنواع مدخلات جديدة تعمل بدون JavaScript.

<form action="/submit" method="POST">
  <!-- مدخل نصي -->
  <label for="name">الاسم الكامل</label>
  <input type="text" id="name" name="name" placeholder="محمد علي" required minlength="2">

  <!-- بريد إلكتروني مع تحقق مدمج -->
  <label for="email">البريد الإلكتروني</label>
  <input type="email" id="email" name="email" required>

  <!-- قائمة منسدلة -->
  <select name="level">
    <option value="">اختر المستوى</option>
    <option value="beginner">مبتدئ</option>
    <option value="pro">محترف</option>
  </select>

  <button type="submit">إرسال الرسالة</button>
</form>
  • <label for="..."> — اربط دائماً التسميات بالمدخلات. مطلوب لسهولة الوصول.
  • required — تحقق أصلي من المتصفح. يظهر خطأً إذا حاول المستخدم الإرسال دون ملء الحقل.
  • type="email" — يتحقق تلقائياً من تنسيق البريد الإلكتروني.
نصيحة للجوال: استخدم سمة type الصحيحة: type="tel" يعرض لوحة أرقام على الجوال، type="email" يعرض لوحة مفاتيح مع @. هذه التفاصيل الصغيرة تحسن تجربة مستخدم الجوال بشكل كبير.

Lesson 9 — Semantic HTML5: Structure That Means Something

SEO Critical

الدرس 9 — HTML الدلالي: بنية ذات معنى

حيوي للسيو

Semantic HTML means using HTML elements that accurately describe their meaning and purpose in the document — not just their visual appearance. This is one of the biggest upgrades HTML5 brought over older HTML.

Compare these two approaches:

<!-- ❌ Non-semantic (old way) -->
<div class="header">...</div>
<div class="nav">...</div>
<div class="content">
  <div class="post">...</div>
</div>
<div class="sidebar">...</div>
<div class="footer">...</div>

<!-- ✅ Semantic HTML5 (correct way) -->
<header>
  <nav>
    <ul>
      <li><a href="/">Home</a></li>
    </ul>
  </nav>
</header>

<main>
  <article>
    <h1>Article Title</h1>
    <section>
      <h2>Introduction</h2>
      <p>Content here...</p>
    </section>
  </article>
  <aside>
    <h2>Related Articles</h2>
  </aside>
</main>

<footer>
  <p>&copy; 2026 Coding Life</p>
</footer>

Key semantic elements:

  • <header> — Introductory content of a page or section
  • <nav> — Navigation links
  • <main> — The main content of the page (use only once)
  • <article> — Self-contained content (blog post, news article)
  • <section> — A thematic grouping with a heading
  • <aside> — Related but secondary content (sidebar, callouts)
  • <footer> — Footer of a page or section
  • <figure> / <figcaption> — Image or media with a caption
  • <time> — A specific date or time (<time datetime="2026-10-15">)
Why semantics matter for SEO: Google's crawler reads your HTML like a screen reader. When it sees <article>, it knows this is the main content. When it sees <nav>, it understands these are navigation links. Semantic HTML can significantly boost your search ranking.

HTML الدلالي يعني استخدام عناصر HTML التي تصف بدقة معناها وغرضها في المستند — ليس مجرد مظهرها. هذا أحد أكبر التحسينات التي جلبها HTML5.

<!-- ❌ غير دلالي (الطريقة القديمة) -->
<div class="header">...</div>
<div class="nav">...</div>
<div class="content">...</div>
<div class="footer">...</div>

<!-- ✅ HTML5 الدلالي (الطريقة الصحيحة) -->
<header>
  <nav>...</nav>
</header>

<main>
  <article>
    <h1>عنوان المقال</h1>
    <section>
      <h2>المقدمة</h2>
      <p>المحتوى هنا...</p>
    </section>
  </article>
  <aside>مقالات ذات صلة</aside>
</main>

<footer>
  <p>&copy; 2026 Coding Life</p>
</footer>
  • <header> — محتوى تمهيدي للصفحة أو القسم
  • <nav> — روابط التنقل
  • <main> — المحتوى الرئيسي للصفحة (استخدم مرة واحدة)
  • <article> — محتوى مستقل (مقالة مدونة، خبر)
  • <section> — تجميع موضوعي مع عنوان
  • <aside> — محتوى ثانوي (شريط جانبي)
  • <footer> — تذييل الصفحة أو القسم
لماذا تهم الدلالة للسيو: يقرأ زاحف Google كود HTML مثل برنامج قراءة الشاشة. عندما يرى <article> يعرف أن هذا المحتوى الرئيسي. HTML الدلالي يمكنه تحسين ترتيبك في البحث بشكل كبير.

Lesson 10 — HTML for SEO & Accessibility

Advanced

الدرس 10 — HTML للسيو وسهولة الوصول

متقدم

This is where HTML knowledge separates good developers from great ones. SEO (Search Engine Optimization) and Accessibility (a11y) are two sides of the same coin — both require clean, meaningful, well-structured HTML.

<!-- Essential Meta Tags for SEO -->
<meta name="description" content="Learn HTML5 from scratch. Free course covering all fundamentals.">
<meta name="keywords" content="HTML, HTML5, web development, tutorial">
<link rel="canonical" href="https://example.com/html.html">

<!-- Open Graph (Social Media Preview) -->
<meta property="og:title" content="HTML5 Complete Course - Coding Life">
<meta property="og:description" content="Master HTML5 from zero to pro.">
<meta property="og:image" content="https://example.com/og-image.jpg">
<meta property="og:url" content="https://example.com/html.html">

<!-- Accessibility: Skip Navigation -->
<a href="#main-content" class="skip-link">Skip to main content</a>

<!-- ARIA Labels for interactive elements -->
<button aria-label="Close dialog"><i class="fa fa-times"></i></button>
<nav aria-label="Main navigation">...</nav>
<img src="chart.png" alt="Bar chart showing monthly sales data for Q4 2026">

<!-- Structured Data (JSON-LD) for rich search results -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Course",
  "name": "HTML5 Complete Masterclass",
  "description": "Free comprehensive HTML5 course",
  "provider": {
    "@type": "Organization",
    "name": "Coding Life"
  }
}
</script>

SEO Checklist for every HTML page:

  • ✅ Unique, descriptive <title> (50-60 chars)
  • ✅ Meta description (150-160 chars)
  • ✅ One <h1> per page with your target keyword
  • ✅ Semantic HTML structure
  • ✅ All images have descriptive alt attributes
  • ✅ Canonical URL link tag
  • ✅ Open Graph tags for social sharing
  • ✅ Structured data (JSON-LD) where applicable
  • ✅ Fast loading (lazy-loaded images, deferred scripts)
  • ✅ Mobile-responsive viewport meta tag
Pro tip: Test your page with W3C Validator (HTML validity), web.dev (performance & SEO), and WAVE (accessibility). All are free tools.

هنا تتمايز معرفة HTML بين المطورين الجيدين والممتازين. السيو وسهولة الوصول وجهان لعملة واحدة — كلاهما يتطلب HTML نظيفاً وذا معنى وبنية جيدة.

<!-- وسوم Meta الأساسية للسيو -->
<meta name="description" content="تعلم HTML5 من الصفر. كورس مجاني يغطي جميع الأساسيات.">
<link rel="canonical" href="https://example.com/html.html">

<!-- Open Graph (معاينة وسائل التواصل) -->

<meta property="og:description" content="أتقن HTML5 من الصفر إلى الاحتراف.">
<meta property="og:image" content="https://example.com/og-image.jpg">

<!-- ARIA Labels للعناصر التفاعلية -->
<button aria-label="إغلاق الحوار"><i class="fa fa-times"></i></button>
<nav aria-label="التنقل الرئيسي">...</nav>
<img src="chart.png" alt="مخطط شريطي يظهر بيانات المبيعات الشهرية للربع الرابع 2026">

قائمة تحقق SEO لكل صفحة HTML:

  • ✅ <title> فريد ووصفي (50-60 حرفاً)
  • ✅ وصف meta (150-160 حرفاً)
  • ✅ <h1> واحد في الصفحة مع الكلمة المفتاحية المستهدفة
  • ✅ هيكل HTML دلالي
  • ✅ جميع الصور لها سمات alt وصفية
  • ✅ وسم URL الرئيسي (canonical)
  • ✅ وسوم Open Graph للمشاركة على وسائل التواصل
  • ✅ بيانات منظمة (JSON-LD) حيثما ينطبق
  • ✅ تحميل سريع (صور كسولة، سكريبتات مؤجلة)
نصيحة للمحترفين: اختبر صفحتك بـ W3C Validator (صلاحية HTML) وweb.dev (الأداء والسيو). كلها أدوات مجانية.
